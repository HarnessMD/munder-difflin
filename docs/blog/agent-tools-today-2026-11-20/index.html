Agent Tools Today, 20 Nov 2026: Codex 0.171.0, Claude Code v2.1.329 and Claude on Black Holes

The top launches, skills, multi agent moves, rising repos and talking points in AI agents from 19 to 20 Nov 2026, each with its source and date.

MD Chaitanya Giri · Nov 20, 2026 · 5 min read News

Agent tools today, 20 Nov 2026: Codex 0.171.0 makes GPT-6.2 Sol its default catalog selection, Claude Code v2.1.329 warns where a folder’s hooks are declared, and Anthropic says Claude agents solved two open physics problems on black holes. It covers 19 Nov 04:00 UTC to 20 Nov 04:00 UTC, checked 20 Nov. Previous edition: 19 Nov.

Top 5 launches #

  1. Codex 0.171.0. Published 20 Nov at 00:44 UTC. It adds “GPT-6.2 Sol and Astra to model catalogs, with Sol as the default catalog selection”. The TUI workspace is now on by default, “with searchable document previews, image previews, and subagent transcripts alongside the main conversation”. codex exec --remote <ADDR> starts or resumes noninteractive sessions on an existing app server. See Codex alternatives. Source
  2. Claude Code v2.1.329. Published 19 Nov at 22:14 UTC. It adds “a trust dialog warning that says where a folder’s hooks are declared”, and /tasks now lists scheduled tasks, /loop wakeups and forks. A remote HTTP MCP server that refuses the connection gets a “Server message” row in /mcp. It fixes ~/.claude.json “sometimes being reset to defaults” after a network stall or file lock. See Claude Code hooks explained. Source
  3. Crush v0.102.0. Published 19 Nov at 17:30 UTC. You can now replace the system prompts, “not just the main agent but prompts for subagents, planning, compaction, session titles and crush init”, with --prompt name=path or option prompt in config. Channels, “an experimental MCP feature from Claude”, “allow MCP servers to push events into your session as they happen”. The server now blocks “dns rebinding and cross-site tcp requests”. Less urgent: a KITT theme. For more open source agents, see Aider alternatives and goose alternatives. Source
  4. OpenClaw 2026.11.6. Published 19 Nov at 17:26 UTC. It keeps “subagent and background turns running through configuration edits” and delivers final answers “when a Gateway restart interrupted sending”. It cuts “startup memory pressure and resident memory on constrained hosts”, and redacts “inline environment credentials in configuration reads”. See OpenClaw alternatives. Source
  5. Hermes Agent v0.23.3. Published 20 Nov at 00:34 UTC. A “Patch release” that “rolls up the ~370 PRs merged since v0.23.2” for the CLI, installers, the Microsoft Store app, Docker and Hermes Cloud. The notes list, without detail, “GPT-6.2 Astra and Sol (+ Pro) on OpenRouter and Nous Portal” and “compaction of idle chats before the 1h cache expires”. Full notes “ship with v0.24.0”. See Hermes Agent alternatives. Source

Top 2 skills, MCP servers and plugins #

  1. Firecrawl Local. A README change on 19 Nov at 17:49 UTC puts Firecrawl Local first: “one binary that turns websites into clean markdown, plugs into your AI agent as an MCP server and serves the Firecrawl API on localhost”. It installs with cargo install firecrawl-local and needs Rust and a C compiler. Another commit in the window removes “the hosted bash endpoint at /v2/bash”. 825 stars in a day on GitHub trending on 20 Nov, 204,375 in total; AGPL-3.0. See what an MCP server is. Source
  2. Cloudflare Computer 0.11.4. “Give your agent a computer”: a virtual filesystem inside a Durable Object, with a Computer MCP example of “one Code Mode code tool backed by a durable workspace, a Worker shell, and a full Linux container”, its repo says. Version 0.11.4, published 19 Nov at 20:52 UTC, adds “passthrough mounts, which serve files straight from your own source without storing them in the workspace”. 9,937 stars; MIT. Source

Top 4 moves from multi agent tools #

  1. Orca v1.4.265. Published 19 Nov at 23:41 UTC, it introduces Orca Bots, which “work like first-class teammates”. Managed agent sessions “are no longer limited to Claude and Codex”, a Slack thread “reflects what its turn is working on”, and Gmail triggers match “the sender’s actual address”. The new Automatic updates setting “defaults to off”. See Orca alternatives. Source
  2. Agent Relay v18.11.0. Published 19 Nov at 15:32 UTC. Question escalation routes “Claude Code’s AskUserQuestion to an inbox” so you can “type the answer back”. It also lets “desktop spawns fork a Grok session” and adds a “shared memory-aware spawn placement policy”. For more tools like these, see Herdr alternatives and Agent Relay alternatives. Source
  3. Paradev desktop v2.0.10. Published 19 Nov at 06:54 UTC; GitHub now sends the old superset-sh/superset address to ParadevAI/Paradev. Paradev now tells clients “when a cloud workspace’s sandbox is asleep”, the desktop gets “the redesigned shell’s finished look, with the command palette rework”, and the composer merges “the agent picker into the model picker”. See Paradev alternatives. Source
  4. crewAI 1.15.44. Published 19 Nov at 17:59 UTC. It adds the “capability to save files as versioned, shareable artifacts”, teaches the flow skill “to save and read artifacts”, and enforces “cwd containment for all FilePath paths”. See CrewAI and AutoGen vs a local agent harness. Source

Top rising repo #

  1. Onlook 2.0. Onlook is “a free, open-source editor for designers and visual engineers who shape their product in real code”, its release notes say. The desktop app includes “the layer that runs Claude Code or ChatGPT on your Mac” and works with the Claude or ChatGPT subscription you already have. v2.0.2 was published 19 Nov at 16:47 UTC. Its Launch HN had 91 points on Hacker News, posted 19 Nov at 16:34 UTC. 27,434 stars; Apache-2.0. Source

Stars can rise for reasons other than use: names to watch, not picks.

Top 2 things people are talking about #

  1. Black holes, solved by an agent team? Anthropic says so. Its post, dated 17 Nov, says Claude “has solved two open problems in theoretical physics”, both about black holes. Asked for open problems, Claude “came back hours later with 22 candidates”; separate agents worked on them “for about six weeks”. The results “were formally verified in Lean”, and “a physicist checked every main result”. This is Anthropic’s own account. 422 points on Hacker News, posted 19 Nov at 17:30 UTC. Source
  2. Which model leads on engineering tasks? Gemini 4 Neon, on one ranking. Mei, the Models Engineering Index, ranks Neon first at 68.0, ahead of Claude Fable 5.2 at 65.3 and GPT-6.2 Astra at 61.5, on data from Cognition, Cursor, the Laude Institute and Vals AI. Its own caveat: “there are no error bars, so small gaps are not meaningful”. 213 points on Hacker News, posted 19 Nov at 23:35 UTC. See Gemini 4 Neon. Source

How this list is built #

We read our scout’s report from Google, Reddit and GitHub for 19 Nov, checked releases, Hacker News and GitHub trending ourselves, and rechecked every item on its own page. Points and stars were checked on 20 Nov. Gemini CLI v0.70.0, LangGraph 1.2.23 and 1.2.24 and LiteLLM v1.110.1 shipped only small changes; OpenWork v0.18.69 and v0.18.71 changed packaging, and emdash v1.2.13 shipped without notes.
