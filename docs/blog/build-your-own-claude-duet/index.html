Build Your Own Claude Duet: A Free Morning Brief Agent

No Claude Duet invite? Build a proactive morning brief in Munder Difflin: one agent, one schedule and Slack replies, with a codebase as the example.

MD Chaitanya Giri · Oct 22, 2026 · 4 min read Guides

You can build your own Claude Duet with one Munder Difflin agent, one daily schedule that asks it for a brief, and Slack for replies. It costs nothing beyond the AI subscription you already have.

Claude Duet, Anthropic’s proactive agent app, opened as a US waitlist on 21 Oct 2026 and is built for business apps (what is Claude Duet?). Its best idea, a brief that comes to you before you ask, works for any work a team of agents can gather: a research digest, a draft weekly report, or items from another app through an MCP server you add. This guide uses a codebase as the worked example. Munder Difflin is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. Labels below match the app’s source on 22 Oct 2026.

What will this build do? #

Every morning at 08:00 an agent checks your repository and writes you a short brief: pull requests waiting for review, checks failing on main, and new issues. When you want something fixed, you say so in Slack and the work starts. Duet does the same for email and invoices: per Anthropic, “each morning, it sends you a short brief on the most important items across your connected apps.”

You need three things:

  • Munder Difflin installed, with the install guide.
  • A coding CLI, such as Claude Code, with a subscription or key.
  • The GitHub CLI signed in, so the agent can run gh pr list, gh run list and gh issue list.

How do you set up the brief agent and its schedule? #

Add one agent, then give it a clock. Press Add agent, pick an engine such as Claude Code, and point it at your repository folder. Call it “brief agent” so the schedule is easy to read.

Then add the schedule. In the Pro view open Automations, press New automation and choose Schedule. In the Classic view, open the Command Center’s Triggers tab, which the app describes as “everything that can start work without you typing”, and add a schedule there. Fill in:

  1. Label: Morning brief.
  2. When: 08:00 every day, or weekdays only. In the Classic view pick every day, at 08:00; in the Pro view choose Weekly and set the days and time.
  3. Sends to: brief agent.
  4. Message: “List open pull requests, failing checks and new issues. Write me a short brief.”

Press Save. The message is sent word for word on every run.

What does the morning brief look like? #

Three short sections, written by the agent from the GitHub CLI’s output. The agent runs the commands in your repository, reads the results and keeps only what needs you. You read it in the agent’s conversation in Inbox, which holds one conversation per agent.

A fuller version of the message stays short and specific:

List open pull requests waiting for my review, checks failing on main,
and issues opened since yesterday. Write me a brief of at most ten lines.
Put anything that blocks a release first.

Tune it with the message, not code. Ask for “only items older than one day”, or “skip draft pull requests”, and the next run follows. Keep it short: Duet checks “every few hours, because checking nonstop would use up your plan’s limits much faster”, and the same holds for your coding plan. One run a day is cheap; a run every ten minutes is not.

Want more than one repository? Add one brief agent per repository, each pointed at its own folder, and give each its own schedule a few minutes apart. Each agent keeps its own memory file, so you can tell it once which items to skip.

How do you answer the brief from Slack? #

Connect Slack once, then reply in a thread. Create the Slack app from the manifest the app gives you: press Copy manifest under How to get these. Our Slack guide has every step. Pick Michael, the orchestrator, as the agent that answers.

Now write “Fix the failing check on main” in a channel the bot is in. The project’s README says Michael “can spawn an ephemeral worker, reply in-thread, and tear it down.”

Spend, scope changes and destructive steps still come back to you for approval, and a circuit breaker stops an agent that loops.

What is still missing compared with Claude Duet? #

Judgment, for now. Duet decides what is urgent on its own and runs in a virtual machine with your laptop off. This build fires on your clock, on your awake computer, and sees only what its commands show; the Cloud Office, coming soon, takes it off your computer. It works with any engine you pick, today, anywhere. For the full picture, read Claude Duet vs Munder Difflin and scheduling agent missions.

FAQ

Is this the same as Claude Duet?

No. Claude Duet is Anthropic's app that works on business apps in its own virtual machine and decides by itself when to message you. This build copies one idea, a brief that comes to you first, with a team of agents on your own computer, on a clock you set.

What do I need for this build?

Munder Difflin, which is free, a coding CLI such as Claude Code with a subscription or key, and the GitHub CLI signed in to your account so the agent can read pull requests, runs and issues. Slack is optional.

Does the brief run if my laptop is asleep?

Not today. Schedules run on your computer, so it has to be awake, and Munder Difflin has a setting that keeps it awake while agents are live. The Munder Difflin Cloud Office, coming soon, keeps agents working with your computer off.

Can I use Codex or Gemini CLI instead of Claude Code?

Yes. Each agent picks its own engine when you add it, so the brief agent can run Codex, Gemini CLI, OpenCode or another supported CLI. The prompt stays the same.
