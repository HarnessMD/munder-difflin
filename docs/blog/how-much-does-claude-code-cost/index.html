Claude Code Pricing (Oct 2026): US and India Plans, Is It Free?

Claude Code starts at $20 a month on Claude Pro (checked 22 Oct 2026). Every plan, API rates, India rupee prices, and whether it is free.

MD Chaitanya Giri · Sep 10, 2026 · 5 min read Concepts

As of 22 Oct 2026, Claude Code pricing starts at $20 a month with Claude Pro ($17 a month billed annually), and every paid plan above it includes Claude Code. The free plan does not. In India, a July 2026 TechCrunch report put Pro at ₹2,000 a month billed annually; check the price your own account sees at checkout.

For light use, the cheapest way in is an API key billed per token. If you run several sessions at once, Munder Difflin is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer, on the subscription or API key you already pay for.

There are nine. Prices are in US dollars from claude.com/pricing, checked 22 Oct 2026, unless the row says otherwise.

Inside Claude Code, /usage-credits opens the spend limit setting (Claude Code cost docs, checked 22 Oct 2026). The pricing page also lists $100 to $200 a month in Claude Platform API credits on Max, and up to $500 a month pooled on Team (checked 22 Oct 2026).

Is Claude Code free? #

No. claude.com/pricing lists Claude Code from Pro upward, not on the free plan (checked 22 Oct 2026). What does exist:

  • API trial credit. Anthropic’s pricing docs say new API users “receive a small amount of free credits to test the API”, with no amount given (checked 22 Oct 2026).
  • Claude for Open Source. Qualifying maintainers (for example 200,000 combined monthly downloads) can apply for six months of Max 20x at no cost, per claude.com/contact-sales/claude-for-oss, checked 22 Oct 2026.
  • A local model. Claude Code can use a model in Ollama, which costs nothing per token. Our guide on connecting Ollama to Claude Code covers the setup and what stops working.

Cloud sessions (Claude Code on the web) count toward your plan’s usage limits, with “no separate charge for the cloud VM” (cloud session docs, checked 22 Oct 2026). The $100 and $250 cloud session credits Anthropic gave Pro and Max subscribers on 23 Sep 2026 had to be claimed by 7 Oct 2026 and expire on 4 Nov 2026 (BleepingComputer, 25 Sep 2026).

What does Claude Code cost in India? #

Pro is ₹2,000 a month billed annually and Max starts at ₹11,999 a month, taxes included, according to TechCrunch’s report of 13 Jul 2026 on Anthropic’s rupee rollout. Team seats started at ₹2,399 in that July 2026 report. Anthropic did not respond to TechCrunch, and claude.com/pricing showed US dollar prices when we checked it from outside India on 22 Oct 2026, so check the price your own account sees at checkout. Anthropic’s API pricing docs list prices in US dollars only (checked 22 Oct 2026).

How much does Claude Code cost on the API? #

It depends on the model, from $0.10 to $10 per million input tokens as of 22 Oct 2026, per Anthropic’s pricing docs:

Model Claude Code alias Input Output Cache hit
Claude Fable 5.1 fable $10 $50 $0.25
Claude Opus 5.5 opus, the default $4 $20 $0.20
Claude Sonnet 5.5 sonnet $2 $10 $0.10
Claude Haiku 5.5 haiku $0.10 $0.50 $0.01

On the Anthropic API the haiku alias now points to Haiku 5.5, and Opus 5.5 is the default on every plan; Fable never is (model configuration docs, checked 22 Oct 2026). As of 22 Oct 2026, Haiku 5.5 prompts over 100,000 tokens cost $0.50 in and $2.50 out, and Opus 5.5 and Sonnet 5.5 cache hits cost 5% of the input price, which matters because Claude Code rereads your conversation from cache every turn.

For a monthly figure, Anthropic’s cost docs (checked 22 Oct 2026) say enterprise deployments average about $13 per developer per active day and $150 to $250 per developer per month, with 90% of users under $30 per active day.

Is a subscription or the API cheaper for Claude Code? #

A subscription, if you use Claude Code most working days. At Anthropic’s $13 per active day average (cost docs, checked 22 Oct 2026), the API passes the $20 Pro price in two days and the $100 Max 5x price in eight. The API wins when you code with Claude a few times a month, or run Claude Code in CI. Our breakdown of whether Claude Code Max is worth it runs that sum for you, and our Max plan guide covers weekly limits.

How do you keep Claude Code costs down? #

Pick the model on purpose and keep context small. From Anthropic’s cost docs, checked 22 Oct 2026:

  • Use /model sonnet for everyday edits, and set model: haiku on subagents that only search or summarise.
  • Run /clear between unrelated tasks. /clear costs nothing; /compact reads the whole conversation, so it is a large request.
  • Keep CLAUDE.md under 200 lines and move workflow instructions into skills, which load only when used.
  • Lower /effort for routine work. Thinking tokens are billed as output tokens.
  • Check /usage. On paid plans it flags any habit behind 10% or more of your recent usage (Oct 2026).

What happens to the bill when you run several agents? #

It multiplies. Each agent has its own context window, all drawing on the same plan or API key. Anthropic’s cost docs (checked 22 Oct 2026) say agent teams in plan mode use about 7 times the tokens of a single session.

Claude Code’s own guard, --max-budget-usd, works in print mode only, according to the CLI reference (checked 22 Oct 2026), so it covers scripted runs, not interactive sessions. Munder Difflin has guards across the whole team: token limits per period (every 5 hours, daily, weekly or monthly) for the office and for each agent, and a circuit breaker that steers, then constrains, then stops an agent that loops, storms errors or blows its budget. None of this changes what Anthropic charges. Our multi agent cost playbook covers other levers.

Anthropic revises these numbers often, so check claude.com/pricing before you commit a team to a plan.

FAQ

Is Claude Code free?

No. As of 22 Oct 2026 the free Claude plan does not include Claude Code; it starts on Claude Pro at $20 a month (claude.com/pricing). The only $0 routes are the small trial credit a new Claude Console API account gets, and Anthropic's Claude for Open Source program, which gives eligible maintainers six months of Max 20x.

How much does Claude Code cost per month?

$17 to $200 a month for one person on a subscription, checked 22 Oct 2026: Pro is $20 billed monthly or $17 billed annually, Max is $100 (5x) or $200 (20x). On an API key there is no monthly fee; Anthropic's cost docs put the average enterprise developer at $150 to $250 a month.

Do Claude Code and Claude chat share the same usage limit?

Yes. On Pro and Max, all activity in Claude and Claude Code counts against the same limits, according to Anthropic's help article on using Claude Code with Pro or Max (checked 22 Oct 2026). A long chat in the afternoon leaves less room for coding in the same five hour window.

Is the API cheaper than a subscription for Claude Code?

For light or occasional use, usually yes, because you pay only for the tokens you use. For daily use a subscription is almost always cheaper: Anthropic's cost docs, checked 22 Oct 2026, put the average enterprise developer on the API at about $13 per active day, which passes the $100 Max 5x price in eight working days.

Does Claude Code cost less in India?

A TechCrunch report of 13 Jul 2026 said rupee prices had begun to appear for some users in India, with Pro at ₹2,000 a month billed annually and Max from ₹11,999, taxes included. Anthropic did not comment on the rollout, so check the price your own account sees at checkout.

How do I see what Claude Code is spending?

Run /usage inside Claude Code. On an API key it shows a session cost estimate at list price; on paid plans it shows plan usage bars and a breakdown by skills, subagents, plugins and MCP servers. The Claude Console usage page is the authoritative bill for API users (code.claude.com/docs/en/costs, checked 22 Oct 2026).
