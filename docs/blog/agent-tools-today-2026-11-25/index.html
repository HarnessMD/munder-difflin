Agent Tools Today, 25 Nov 2026: Skills over MCP, Claude Apps and Ternary Bonsai 2.5

The top launches, skills, multi agent moves, rising repos and talking points in AI agents from 24 to 25 Nov 2026, each with its source and date.

MD Chaitanya Giri · Nov 25, 2026 · 5 min read News

Agent tools today, 25 Nov 2026: Anthropic put Skills over MCP in public beta, Claude artifacts began rolling out in beta as Mac and Windows apps, and PrismML released Ternary Bonsai 2.5 27B. It covers 24 Nov 03:45 UTC to 25 Nov 09:30 UTC, checked 25 Nov. Previous edition: 24 Nov.

Top 5 launches #

  1. Skills over MCP. Anthropic’s post of 24 Nov puts Skills over MCP “in public beta in Claude, so MCP servers can ship skills alongside their tools”. Tasks, which run long jobs “while Claude keeps working”, and Elicitation, which can “pause to ask the user for input”, are “now generally available”; File Uploads “is rolling out soon”. MCP turns two, with “over 10,000 MCP connectors for Claude”. Source
  2. Install as app. Anthropic’s post of 24 Nov says the “Install as app” feature “is rolling out in beta in Claude for Mac and Windows”. An installed artifact “gets its own icon and opens in its own window”, can use your connectors, and Claude asks for permission again “after every update”. Its requests “count toward your plan’s usage limits”. Source
  3. Ternary Bonsai 2.5 27B. PrismML’s post of 24 Nov calls it an upgrade “with substantially stronger agentic coding, multi-turn tool use, and multi-step task execution”, based on Qwen3.8 27B, with a “5.9 GB model footprint” and Apache 2.0 weights. It scores 75.6 on SWE-bench Verified, up from 60.8 for Bonsai 2: PrismML’s own figures. 444 points on Hacker News, posted 24 Nov at 20:08 UTC. Source
  4. Claude Code v2.1.332. Published 25 Nov at 01:32 UTC. It adds “skills from MCP servers (beta)”, shown as server:skill in the / menu, and a PreSkillShellCommand hook event “that can refuse a skill or command’s inline shell commands as it loads”. See Claude Code Max plan tips. Source
  5. goose v1.61.0. Published 25 Nov at 03:31 UTC. It can “Import MCP’s server.json format into goose config”, makes tool approval optional for execution, and adds Gemini 4 Neon to its catalog. See goose alternatives. Source

Top 4 skills, MCP servers and plugins #

  1. Chrome DevTools MCP 1.14.0. Published 24 Nov at 14:59 UTC. It adds an “inspect-in-devtools skill and claude plugin command”, --backgroundNewPages and transparent screenshots, and lists “errors a page raises while a tool runs”. Source
  2. Versine. Its team’s Launch HN says to “think Venmo with an MCP”: your agent can send and request money, each user has “a self-custodial stablecoin wallet storing USDC on Base”, and sending needs your approval “(via passkey in our app)” unless you mark the contact as trusted. Its site calls it “a fintech company, not an FDIC-insured bank”. 87 points on Hacker News, posted 24 Nov at 20:44 UTC. Source
  3. Caveman. “why use many token when few token do trick”, its repo says: a “Skill + local proxy for coding agents”. Docs commits landed on 24 Nov. 122,719 stars on 25 Nov; Apache-2.0. More in what Caveman is. Source
  4. UI UX Pro Max. “An AI skill that provides design intelligence for building professional UI/UX”, its repo says. A commit on 24 Nov adds “exact hex palette lookup”. 153,943 stars on 25 Nov; MIT. More in what UI UX Pro Max is. Source

Top 4 moves from multi agent tools #

  1. OpenClaw 2026.11.10. The release, published 25 Nov at 05:42 UTC, rolls up “7,671 pull requests”. Deep Research, “enabled by default”, returns “a cited report with side-by-side quotes when sources disagree”; Knowledge, which you opt into, builds “a linked local Markdown vault”. See OpenClaw alternatives. Source
  2. T3 Code v0.1.12. Published 25 Nov at 07:36 UTC with “1092 changes from 226 contributors”. Projects can “Work across several repositories”, and Workflows (beta) run “durable workflows with agents, schedules, webhooks, and human approvals”. See T3 Code alternatives. Source
  3. OpenHands 1.45.0. Published 24 Nov at 09:13 UTC. It adds “OpenHands Projects in Canvas (experimental)” and nests “sub-agent conversations under their parent”. See OpenHands alternatives. Source
  4. Orca v1.4.273 and v1.4.274. Published 24 Nov at 10:20 and 22:52 UTC. In v1.4.273, “Bot panels show upcoming runs” and the phone app can “post to groups across computers”; v1.4.274 turns App Rail on for new users. See Orca alternatives. Source

Top 2 rising repos #

  1. diagram-design. “Editorial diagram design for Claude Code, Codex, GitHub Copilot, Cursor, Factory Droid, Qoder, and Pi”, its repo says, with 52 diagram types. Fixes landed on 25 Nov. 802 stars in a day on GitHub trending on 25 Nov, 72,479 in total; MIT. Source
  2. Brickie. Hatchet’s repo says it lets you “run durable sandboxes in your own cloud / k8s cluster”, with snapshots that are “immutable and forkable”. It “is in beta”; its README was rewritten on 24 Nov. Created 28 Aug; 126 stars; MIT. Source

Stars can rise for reasons other than use: names to watch, not picks.

Top 4 things people are talking about #

  1. Do agents work for you or for their makers? For their makers, Michael Harley argues in his essay of 1 Nov. Claude would not help his music buying skill past a new Bandcamp challenge, so he wants “a local model that runs in my homelab”: models work for us “only insofar as Anthropic or OpenAI or whoever else allows them to”. 973 points on Hacker News, posted 24 Nov at 12:40 UTC. Source
  2. Is the matrix multiplication exponent 9/4? The README of OpenAI’s preprint of 24 Nov says “The exponent of square matrix multiplication is 9/4 over every field”, and that a Lean development proves it “for division-free circuits computing formal polynomial identities”. It is a preprint. 628 points on Hacker News, posted 25 Nov at 01:19 UTC. Source
  3. Can sandboxed models talk to each other? Yes, through a shared inference server, Niranjan Deshpande and David Africa write on LessWrong: signals pass through “the way vLLM chooses kernels”. One model guessed the other’s colour “in 1,221/1,221 rounds”, though the post calls its initial setups “quite contrived”. 229 points on Hacker News, posted 25 Nov at 02:34 UTC. Source
  4. Can GPT-6 design proteins? OpenAI says its GPT-6 models can, “using only reasoning and code”. In lab tests with Onava, designs “showed evidence of binding” across five targets, with help from specialized models. This is OpenAI’s own account of 24 Nov. 264 points on Hacker News, posted 24 Nov at 21:02 UTC. Source

How this list is built #

We checked releases, the Hacker News front page and GitHub trending ourselves, used two scouts’ notes (Google sources and X) as leads, and rechecked every item on its own page. Points and stars were checked on 25 Nov. The 24 Nov brief missed Claude Ship, which Anthropic introduced on 23 Nov: see what Claude Ship is. Claude Agent SDK v0.2.189 shipped without notes, Agent Relay made only small fixes, and Hermes Agent v0.23.4 holds its notes for v0.24.0. LiteLLM v1.111.0 and Copilot CLI v1.0.115 are left out for space.
