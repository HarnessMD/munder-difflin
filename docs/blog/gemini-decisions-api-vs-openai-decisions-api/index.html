Gemini Decisions API vs OpenAI Decisions API: Price, Inputs and Limits

Gemini Decisions API vs OpenAI Decisions API: both list $0.10 per 1M input tokens. Inputs, models, status, limits and which to pick, checked 12 Nov 2026.

MD Chaitanya Giri · Nov 12, 2026 · 5 min read Comparisons

Our view: pick the Gemini Decisions API for audio, video or PDF inputs and up to 1,000 questions a call, and the OpenAI Decisions API for a generally available endpoint with prompt caching and JSON input. On 12 Nov 2026 both list $0.10 per 1M input tokens with no output charge. Checked 12 Nov 2026.

Google launched its API on 11 Nov 2026; OpenAI’s went generally available on 22 Oct, per its changelog. Both answer fixed questions with numbers instead of text. More in our Comparisons hub and OpenAI Decisions API explainer. To run several agents rather than score inputs, see Herdr alternatives.

Gemini Decisions API vs OpenAI Decisions API at a glance (checked 12 Nov 2026) #

Both return probabilities for questions you write and bill only input tokens; they differ on inputs, caps and status.

What is the Gemini Decisions API? #

It is a Gemini API endpoint that scores answers you supply instead of writing text. Google’s launch post calls it “a new endpoint for fast, closed-set decisions powered by our new Gemini Decision 1 model (gemini-decision-1)”. The docs add that it “generates zero text tokens, so output token usage is always 0.”

You send one shared input of text, images, audio, video or PDF, plus 1 to 1,000 questions. Each question is one of three types. A yes or no question returns a probability from 0.01 to 0.99. A choice question picks from 2 to 255 options. A score question rates the input against ordered rubric levels. Every answer carries a confidence value. The yes or no type really is spelled noul in Google’s docs and code samples.

The docs give a context window of 262,144 tokens across the input and all questions. The API “doesn’t support context caching, Batch API, or Flex or Priority inference”, so “Repeated input across requests counts in full.” The rate limits page lists 200 requests a minute and 10,000 a day free, and 1,500 a minute on Tier 1.

On status, the docs say “Available on the Gemini Developer API (v1beta)”. No preview or GA label appears on the pages, and Vertex AI is not named. The launch post says support is “coming soon to Gemini in Google Cloud”.

Google’s own figures: 150 to 250 ms end to end, “the lowest calibration error” on its benchmarks, and “nearly 5x cheaper across the shared benchmark suite than Gemini 3.5 Flash-Lite with the Interactions API.”

What is the OpenAI Decisions API? #

It is OpenAI’s POST /v1/decisions endpoint, generally available since 22 Oct 2026 with one model, gpt-6-luna. The Decisions guide says it “evaluates text, images, and JSON and returns typed answers about 10x faster than the Responses API”. That speed figure is OpenAI’s own.

Since the public beta, the guide has added prompt caching, JSON input, images inside questions, hosted image URLs and conversation history with tool calls. It allows “up to 400 questions per request, up from 200 during the public beta.” It still takes no audio: “Files, audio, and item references aren’t supported.”

The question types are predicate, which returns a probability from 0 to 1, choice and score. Choice and score answers add “a probability distribution and a separate confidence field.” Zero Data Retention and HIPAA use are supported “for eligible customers”. The guide states no rate limit for the endpoint.

How much do they cost? #

They list the same price: $0.10 per 1M input tokens on 12 Nov 2026, and nothing for output. The difference is in what you pay for repeated input.

On 12 Nov 2026 Google’s pricing page listed Gemini Decision 1 as free of charge on the free tier and $0.10 per 1M input tokens on the paid tier. Each request “bills shared input tokens once, regardless of question count.”

On 12 Nov 2026 OpenAI’s guide said “uncached input costs $0.10 per 1M tokens”, with cache hits discounted and cache writes charged. OpenAI’s pricing page listed gpt-6-luna cached input at $0.01 per 1M tokens on 12 Nov 2026. The cached prefix needs at least 1,024 tokens. Regional processing premiums and long context multipliers apply.

Our view: OpenAI’s caching suits one long document asked new questions across many calls; Google’s single bill for shared input suits many questions in one call.

Which should you pick? #

Pick by input type, question count and status.

Pick the Gemini Decisions API if:

  • Your input is audio, video or a PDF.
  • You ask more than 400 questions of one input.
  • You want a free tier to prototype in Google AI Studio.

Pick the OpenAI Decisions API if:

  • You need an endpoint marked generally available today.
  • You resend a long shared input and want cache discounts.
  • Your evidence is JSON or a conversation with tool calls.

Our view: set thresholds from your own labelled examples, as OpenAI’s guide advises, and keep “a human or a second check on high-stakes actions such as payouts”, as Google’s docs put it.

Can a team of agents use a decisions API? #

Yes, as a fast step between agents, not as an agent. Google’s docs list “Decide which tools an agent needs, or whether to compact, escalate, or stop” as a use. OpenAI’s guide puts the split plainly: “Decisions returns typed answers; your application runs any actions those answers select.”

Our view: use it to route a task to the right agent or the right model, or to flag work for a person, and leave the writing to a model that writes.

FAQ

What is the difference between the Gemini Decisions API and the OpenAI Decisions API?

Mostly inputs, caps and status. Google's docs say the Gemini Decisions API reads text, images, audio, video and PDFs, takes up to 1,000 questions a request and is available on the Gemini Developer API (v1beta). OpenAI's guide says its Decisions API reads text, images and JSON, takes up to 400 questions and is generally available. Checked 12 Nov 2026.

How much does the Gemini Decisions API cost?

On 12 Nov 2026 Google's pricing page listed Gemini Decision 1 at $0.10 per 1M input tokens on the paid tier and free of charge on the free tier. Output is listed as not applicable, because the model generates 0 output tokens. Context caching is not available for it.

Is the OpenAI Decisions API still in beta?

No. OpenAI's changelog entry for Oct 22 says the Decisions API is now generally available with gpt-6-luna. The same entry raised the cap to 400 questions per request, up from 200 in public beta. Checked 12 Nov 2026.

Is the Gemini Decisions API on Vertex AI?

Vertex AI is not stated on Google's pages. The launch post says the API is "available through the Gemini API in Google AI Studio", "with support coming soon to Gemini in Google Cloud." The docs list the Gemini Developer API (v1beta) only. Checked 12 Nov 2026.

Can either decisions API write text or code?

No. Google's docs say the Gemini Decisions API generates zero text tokens and point to the Interactions API for generated text. OpenAI's guide points to Structured Outputs or function calling when you need written output or a tool call.
