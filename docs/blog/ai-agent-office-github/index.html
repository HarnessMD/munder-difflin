Open Source AI Agent Office Apps on GitHub (Oct 2026)

Open source AI agent office apps on GitHub, checked 23 Oct 2026: ChatDev, Munder Difflin, OpenHands, CrewAI, AG2 and three more, with licences.

MD Chaitanya Giri · Oct 23, 2026 · 5 min read Comparisons

An AI agent office is an app that runs several AI agents as one team, with roles, a shared board and messages. The open source ones on GitHub worth a look are ChatDev, Munder Difflin, OpenHands, CrewAI, AG2, Pixel Agents, AgentOffice and Claude Squad. Checked 23 Oct 2026.

Licences and dates come from GitHub, read on 23 Oct 2026. This list sits in our Comparisons hub, next to our wider pick of open source AI agents.

What is an AI agent office app? #

It is a desktop or web app where several AI agents work as one team on your jobs. Three parts make it an office rather than a chat window:

  • Roles. Each agent has a job, such as researcher, writer or reviewer.
  • A shared board. Tasks sit where you and every agent can see them.
  • Messages. Agents hand work to each other and ask you when they are stuck.

The work does not have to be code; research, reports and spreadsheets fit the same shape. Our multi agent harness explainer covers the idea, and Run an office of AI agents shows a working day.

Which open source agent office apps are on GitHub? #

Eight projects pass three tests: an open source licence, a commit in the last three months, and a README that describes several agents working together.

1. ChatDev. ChatDev from OpenBMB began as a “Virtual Software Company” with agents such as CEO, CTO and Programmer. Its README calls version 2.0, released on 7 Jan 2026, “a Zero-Code Multi-Agent Platform for Developing Everything”, run from a web console. Apache 2.0. Best for: designing an agent team without code.

2. Munder Difflin. This is what we make. Munder Difflin is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. MIT licence, code at HarnessMD/munder-difflin. A Cloud Office and a mobile app are coming soon. The install guide goes from download to a first agent. Best for: a ready office for technical and non technical work.

3. OpenHands. OpenHands now leads its README with Agent Canvas, which “turns your coding agents into a self-hosted, always-on engineering team”. It runs its own agent or Claude Code, Codex, Gemini, Pi and OpenCode, on a laptop or a server. MIT. Best for: a coding team that keeps working with your laptop shut.

4. CrewAI. CrewAI is “an open-source Python framework” for multi agent workflows, with “role-based AI agents”. It is a library you code against, not an app; a paid AMP Suite adds a control plane. MIT. Best for: Python developers building their own office.

5. AG2. AG2, formerly AutoGen, is “an open-source programming framework for building AI agents and facilitating cooperation among multiple agents”. Apache 2.0. Best for: AutoGen style teams that still get updates.

6. Pixel Agents. Pixel Agents turns the coding agents in your terminals into “animated pixel-art characters working in a tiny office”, in VS Code or a browser. Claude Code is the agent it supports today, and its README lists a task board as a plan: “Most of this is still ahead.” MIT, v1.5.0 on 17 Oct 2026. Best for: seeing which agent is busy.

7. AgentOffice. AgentOffice promises “Self-growing AI teams in a pixel-art virtual office” on local models through Ollama. Agents talk, take tasks from a TaskBoard and can hire new team members on their own, which is more autonomy than most interns get. MIT, last commit 25 Sep 2026. Best for: tinkering with a local, visual team.

8. Claude Squad. Claude Squad is “a terminal app that manages multiple” agents such as Claude Code, Codex and Gemini, each task in “its own isolated git workspace”. No roles or board; it is the lean option. AGPL 3.0, v1.0.20 on 20 Aug 2026. See Claude Squad vs Munder Difflin.

Is an agent framework the same as an agent office app? #

No. A framework is a library you write code against; an office app is something you open and use. ChatDev, Munder Difflin, OpenHands and AgentOffice are apps you run. CrewAI and AG2 are what you would build one with. Our view: if you do not want to write Python, start with an app. How to choose a multi-agent tool has a checklist, and CrewAI and AutoGen vs a local agent harness covers the split.

Which projects did we leave out, and why? #

Six well known names failed the check on 23 Oct 2026:

  • MetaGPT. MIT and famous for its AI software company, but its last commit was 21 Jan 2026 and its last release, v0.8.1, is from April 2024.
  • AutoGen. Its README says “Project archived and no longer maintained” and points to Microsoft Agent Framework. AG2 carries the AutoGen line on.
  • AI Town. MIT, but it is “a virtual town where AI characters live, chat and socialize”. Nobody files a report.
  • Claw Empire and Star Office UI. Pixel offices with no commit since March 2026; GitHub could not match Star Office UI’s licence to a standard one.
  • AionUi. Apache 2.0 and busy, but we read it as a cowork app with many agents in one window, not a team with roles and a board.

Which agent office app should you pick? #

Pick by whether you want to write code and what work the team does.

  • ChatDev to design an agent team without code.
  • Munder Difflin for a ready desktop office for any knowledge work, coding included.
  • OpenHands for an always on coding team on a server.
  • CrewAI or AG2 to build your own in Python.
  • Pixel Agents or AgentOffice to watch agents as pixel art.
  • Claude Squad for parallel coding sessions in the terminal.

FAQ

What is an AI agent office?

A desktop or web app that runs several AI agents as one team. Each agent has a role, the tasks sit on a shared board, and the agents pass messages to each other and to you. The work can be code, research, writing or any other knowledge work.

Is there a free, open source AI agent office app?

Yes. All eight projects on this list carry an open source licence on GitHub, checked on 23 Oct 2026. The software is free; you still pay for the model behind it, unless you run a local one. AgentOffice, for example, runs on local models through Ollama.

Is MetaGPT still maintained?

Not actively, as far as GitHub shows. On 23 Oct 2026 its last commit was from 21 Jan 2026 and its last release, v0.8.1, was from April 2024. The code is still MIT licensed and usable.

What happened to AutoGen?

Microsoft's AutoGen README now says the project is archived and no longer maintained, and points new users to Microsoft Agent Framework. AG2, which describes itself as formerly AutoGen, is still active and Apache 2.0 licensed.

Can an AI agent office do work that is not coding?

Yes, if the app is built for it. ChatDev 2.0 describes itself as a platform for developing everything, and Munder Difflin runs agents for all kinds of knowledge work, coding included. OpenHands, Pixel Agents and Claude Squad are built around coding agents.
