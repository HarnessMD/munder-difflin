goose Alternatives: 5 Open Source AI Agents (Nov 2026)

goose is part of the Agentic AI Foundation. Five open source alternatives by licence, release and fit, checked 20 Nov 2026.

MD Chaitanya Giri · Nov 20, 2026 · 5 min read Comparisons

Our view: Hermes Agent is the best goose alternative for most people, as it is also an open source general agent that works with any model. We think people look for goose alternatives when they want a team of agents, chat app access, or a tighter coding focus. Checked 20 Nov 2026.

We make Munder Difflin, which is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. More lists: the best AI coding agents and OpenHands alternatives.

What is goose? #

goose is an open source general agent. Its README, read 20 Nov 2026, says “goose is a general-purpose agent for coding, research, writing, automation, and data analysis.” It adds: “Use the native desktop app on macOS, Linux, or Windows, or work from the terminal with the CLI. Connect tools and data through the Model Context Protocol (MCP).” It can load local models or “connect to over 85 providers, including Anthropic, OpenAI, Gemini, OpenRouter, and Amazon Bedrock”. The repo calls it “an open source, extensible AI agent”, Apache 2.0 licensed, with 56,796 stars on 20 Nov 2026.

The README also says “goose is part of the Agentic AI Foundation (AAIF) at the Linux Foundation.” On 20 Nov 2026 GitHub sent the old block/goose address to aaif-goose/goose with a permanent redirect.

The newest stable release is v1.60.1, published 18 Nov 2026, a bug fix release. On macOS, the install docs offer the desktop app as a download or with brew install --cask block-goose, and the CLI with a download script or brew install block-goose-cli.

Why look for a goose alternative? #

Our view: goose is one agent, so look elsewhere if you want several agents working together, an agent you reach from chat apps, or a tool made only for code. Its README leads with oi-kit, which “provides the reusable Rust components for building agents” and “is in alpha”.

What are the best goose alternatives? #

Five open source tools, as of 20 Nov 2026. The four from other makers each shipped a stable release between 18 and 20 Nov 2026.

1. Hermes Agent: the closest general agent #

Its README, read 20 Nov 2026, calls it “The self-improving AI agent built by Nous Research.” It says “Use any model you want” and lists “Telegram, Discord, Slack, WhatsApp, Signal, and CLI” as places to talk to it. It “Runs anywhere, not just your laptop”, with backends such as “local, Docker, SSH, Modal, Daytona, and Vercel Sandbox”. Its site offers Hermes Desktop and says “Hermes Agent is free and open source under the MIT license.” On 20 Nov 2026 it listed Nous Portal model plans, with Plus at “$20 / month”. The repo had 264,784 stars on 20 Nov 2026, and v0.23.3 went up on GitHub that day. We think it suits people who want one agent they can reach from anywhere.

2. Munder Difflin: a team of agents for any work #

Munder Difflin gives you a team of agents, not one agent. Its README, read 20 Nov 2026, says you “hand them work in plain words: research, writing, analysis, planning, support, operations, and code too.” It also says “Each agent runs the real CLI you already use, signed in with your own plan”, with engines such as Claude Code, Codex and Gemini CLI. Agents can use MCP servers, skills and plugins, and pick up work from Slack or webhooks. The Cloud Office runs your agents in the cloud, always on, so work goes on with your computer off. We think it suits people who want a team of agents for any work, code included. Setup: how to install and use Munder Difflin.

3. OpenCode: an open source coding agent #

Its README, read 20 Nov 2026, calls it “The open source AI coding agent.” It runs in a terminal and is “also available as a desktop application”, marked beta. It is MIT licensed with 228,072 stars on 20 Nov 2026. GitHub published v2.3.2 on 18 Nov 2026 and marks the older v1.19.6 as Latest; npm lists 2.3.2 as the latest @opencode/cli. Its site says “OpenCode comes with a set of free models. No account needed.” On 20 Nov 2026 it offered OpenCode Go “from $10/month”. More terminal picks: Aider alternatives.

4. OpenHands: a control center for coding agents #

OpenHands runs other agents for you. Its README, read 20 Nov 2026, calls Agent Canvas “The self-hosted developer control center for coding agents and automations.” It can “Run OpenHands, Claude Code, Codex, Gemini, Pi, OpenCode, or any ACP-compatible agent”. It is MIT licensed with 93,863 stars on 20 Nov 2026, and v1.42.0 came out on 18 Nov 2026. On 20 Nov 2026 the pricing page listed Open Source as “Free” and Teams at “$500/month” with “10 users included”. We think it suits teams that want several coding agents in one place.

5. Codex CLI: OpenAI’s open source agent #

Its README, read 20 Nov 2026, says “Codex CLI is a coding agent from OpenAI that runs locally on your computer.” It is Apache 2.0 with 135,906 stars on 20 Nov 2026, and 0.171.0, tagged rust-v0.171.0, came out the same day. On 20 Nov 2026 OpenAI’s pricing page put the CLI in Plus at $20 a month, or on an API key. We think it suits people who already pay for ChatGPT.

How to choose #

Pick by how you want to work. Our view:

  • A general agent you reach from chat apps: Hermes Agent.
  • A team of agents for any knowledge work, on your computer or in the Cloud Office: Munder Difflin.
  • A coding agent in a terminal or a desktop app: OpenCode.
  • A control center that runs several coding agents: OpenHands.
  • OpenAI’s agent on a ChatGPT plan: Codex CLI.
  • One general agent with a desktop app, a CLI and MCP: stay on goose.

FAQ

What is goose?

Its README, read 20 Nov 2026, says "goose is a general-purpose agent for coding, research, writing, automation, and data analysis." It has a desktop app for macOS, Linux and Windows and a CLI, connects tools through the Model Context Protocol (MCP), and is Apache 2.0 licensed.

Who runs goose now?

Its README, read 20 Nov 2026, says "goose is part of the Agentic AI Foundation (AAIF) at the Linux Foundation." The repo lives at aaif-goose/goose, and on 20 Nov 2026 the old block/goose address redirected there.

What is the latest goose release?

v1.60.1, published on GitHub on 18 Nov 2026, was the newest stable release on 20 Nov 2026. It is a bug fix release that follows v1.60.0 of 17 Nov 2026.
