What is Claude-BugHunter? A Claude Code Skill Bundle for Bug Hunting

Claude-BugHunter (elementalsouls) is a Claude Code skill bundle for bug hunting. What is inside, how to install it, and the written authorisation it expects.

MD Chaitanya Giri · Nov 27, 2026 · 5 min read Concepts

Claude-BugHunter is “a self-contained Claude skill bundle for bug hunting and external red-team work”, per its README. It is a set of Claude Code skills and slash commands, published on GitHub by elementalsouls. Checked 27 Nov 2026.

If you run AI agents, Munder Difflin is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. Its agents run on engines such as Claude Code, Codex and Gemini CLI. The install guide covers setup.

What is Claude-BugHunter? #

Claude-BugHunter is “a drop-in skill bundle for the Claude Code skills system”, in the README’s words. You do not call its skills by name: “describe what you’re testing in plain English and the relevant skill loads.”

The README stacks four layers, which it calls Think, Hunt webapps, Hit the perimeter and Ship it. It covers the “external attack surface”, which it defines as “anything reachable from the internet without first compromising an internal endpoint”. Its “In scope” list starts with “Bug bounty hunting” and “Web application pentesting”, and ends with “Reporting”.

The README also lists what it leaves out, such as internal Active Directory attacks and C2 frameworks. It calls these “not gaps, design decisions”.

What is inside Claude-BugHunter? #

It holds 85 skills and 16 slash commands, the project’s own figures. On 27 Nov 2026 the repo’s skills folder held 85 folders and its commands folder 16 files. The README sorts the skills into five categories:

Category, per the README Skills
Hunt, web app vuln classes 58
Enterprise platform attack 10
Reporting and validation 7
Recon and OSINT 5
Methodology and mindset 5

The README’s examples for the hunt category include XSS, SSRF and IDOR. Reporting skills include triage-validation, evidence-hygiene and report-writing. The slash commands include /hunt and /report.

The hunt skills draw on what the README calls “681 disclosed-report patterns (433 now individually cited & auditable) across 24 core vulnerability classes”. It says those patterns come from disclosed HackerOne reports.

How do you install Claude-BugHunter? #

The README recommends installing it as a Claude Code plugin. From inside Claude Code:

/plugin marketplace add elementalsouls/Claude-BugHunter
/plugin install claude-bughunter@elementalsouls

Per the README, “All 85 skills + 16 commands load namespaced under claude-bughunter:”. The install asks for a HackerOne API username and token, but “A HackerOne account is optional.” Leave both blank if you do not need the HackerOne MCP to read your private programs and your own reports.

Or copy the files in from a clone, which the README calls Option B:

git clone https://github.com/elementalsouls/Claude-BugHunter.git
cd Claude-BugHunter
# macOS / Linux
bash scripts/install.sh

# Windows (PowerShell)
pwsh ./scripts/install.ps1

Both copy the skills and commands into ~/.claude/ on macOS and Linux, the README says. Then open Claude Code and describe your task in plain English, or start a slash command such as /hunt. The INSTALL.md guide lists Claude Code as a prerequisite, plus Python 3.9 or later for its cbh CLI runner.

Its SECURITY.md adds: “Agent Skills are third-party code”, so “treat them like any dependency you run”. It says “Review before you trust” and to pin to a reviewed tag or commit “rather than tracking main”.

Who is Claude-BugHunter for, and what must you have first? #

It is for authorised security work, and you need permission before you start. The README’s Authorization section says: “These skills are intended for assets you own or have written authorization to assess (bug-bounty in-scope assets, pentest engagement letters, CTF challenges, your own infrastructure).”

The README says the “7-Question Gate” in triage-validation “explicitly asks whether the asset is in scope (Q3)”, and that /hunt “states the engagement frame (authorized, scope-bounded, remediable finding) on its first turn”. It says the bundle “explicitly excludes” items such as “weaponizing 0-days against unauthorized targets” and “malware development”. SECURITY.md says the bundle is not intended for any activity that violates laws such as the Computer Fraud and Abuse Act or the UK Computer Misuse Act. It ends: if you are unsure, “stop and verify in writing” before proceeding.

The README also warns that Anthropic’s safeguards mean “even authorized, in-scope work can hit a refusal”. It says: “Do not reword an offensive engagement to look defensive to get past a classifier”. It points to Anthropic’s Cyber Verification Program, which Anthropic says “lets verified security professionals use our most capable models for advanced security work with fewer interruptions from our cyber safeguards”. That page says bug bounty hunters can apply for Defense Access, and “It isn’t available on the Free plan.”

Our view: test only systems you have written permission to test, read the program’s scope before each session, and keep your agent inside it. Security for AI Coding Agents: A Practical Guide covers habits for any agent.

How does Claude-BugHunter fit with other Claude Code skills? #

Its skills are plain SKILL.md files, the format Claude Code loads for any skill. The README says Claude Code, OpenCode, OpenAI Codex CLI, Hermes Agent and Google AntiGravity all load them, while “the slash commands and /hunt engine stay Claude-Code-only by design.”

FAQ

Is it legal to use?

The README says the skills "are intended for assets you own or have written authorization to assess (bug-bounty in-scope assets, pentest engagement letters, CTF challenges, your own infrastructure)." Its SECURITY.md says the bundle is not intended for any activity that violates laws such as the Computer Fraud and Abuse Act or the UK Computer Misuse Act. Our view: use it only on systems you are allowed to test, get written permission first and keep to the program's scope.

How do I install Claude-BugHunter in Claude Code?

Per the README, from inside Claude Code run `/plugin marketplace add elementalsouls/Claude-BugHunter`, then `/plugin install claude-bughunter@elementalsouls`. Or clone the repo and run `bash scripts/install.sh` on macOS or Linux, or `pwsh ./scripts/install.ps1` on Windows.

Do I need a HackerOne account?

No. The README says "A HackerOne account is optional." The username and token only let the HackerOne MCP read your private programs and your own reports, and every skill and command works without them.

Does Claude-BugHunter work outside Claude Code?

The skills do, per the README: they load in Claude Code, OpenCode, OpenAI Codex CLI, Hermes Agent and Google AntiGravity. The README says "the slash commands and `/hunt` engine stay Claude-Code-only by design."

What licence is Claude-BugHunter under?

Two licences, per the README: the code (Python helpers and shell scripts) is MIT, and the content (skill methodology, wordlists, docs) is Creative Commons Attribution 4.0. The GitHub API lists the repo as MIT, checked 27 Nov 2026.
