What is Claude Ship? Anthropic's pull request agents

Claude Ship is Anthropic's set of GitHub pull request agents: Code Review, PR Steward and Claude Approvals. Plans, billing, limits and the /ship command.

MD Chaitanya Giri · Nov 24, 2026 · 5 min read Concepts

Claude Ship is Anthropic’s set of agents for GitHub pull requests, announced on 23 Nov 2026. In Anthropic’s words, “Claude can now review pull requests, fix them, and approve the ones that a team’s policy allows.” It has three agents, Code Review, PR Steward and Claude Approvals, on Team and Enterprise plans. Checked on 24 Nov 2026.

If you run AI agents, Munder Difflin is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. Its agents run on engines such as Claude Code, Codex and Gemini CLI. The install guide covers setup.

What is Claude Ship? #

Per the Claude Ship docs, it is “a set of agents that help get your team’s GitHub pull requests ready to merge”, launched in beta on 23 Nov 2026. “Together, they can take a pull request through review, fixes, and an approval decision,” the docs say.

Anthropic’s product page adds: “Using Claude Ship does not require using Claude Code.”

What are the three Claude Ship agents? #

They are Code Review, PR Steward and Claude Approvals, adopted “each one separately, repo by repo”, per the product page.

Code Review #

Several agents read each change “alongside the surrounding code”, and a verification step checks findings, per the Code Review docs. “By itself, a review doesn’t approve or block the pull request.” Review levels are Quick, Standard and Deep.

PR Steward #

PR Steward “pushes commits to address review feedback, and attempts to fix failing checks and resolve merge conflicts”, per the PR Steward docs. It works in a cloud session and “pushes commits and replies to comments without asking first”. To stop it on one pull request, remove the claude-pr-steward-watching label or comment @claude stop.

Claude Approvals #

Claude Approvals is “a check on GitHub pull requests that reports who still has to approve”, per the Approvals docs. Rules in .claude/approvals.yml set how many people a path needs and whether Claude may approve.

What stays with you and GitHub? #

The merge does: “Your settings and GitHub branch rules determine what merges,” per the Claude Ship docs. PR Steward “is designed not to approve or merge pull requests”.

Where Anthropic hosts the session, its service refuses PR Steward’s requests to approve a pull request, change branch protection, rulesets or statuses, write check runs, delete a branch or push tags, per What PR Steward can access. “Merging, turning on auto-merge, and force-pushing” are left to GitHub’s branch rules. Two checks screen those commands, but “a command that’s written another way can pass both.” So setup asks for a required approval on the default branch, with the Claude GitHub App off the bypass list.

The Approvals check “blocks a merge only where you make it a required check in GitHub, and normally not in observe mode.” Where a branch rule requires one approval, “Claude’s approving review can be that approval.” The docs warn: “If you use GitHub auto-merge or a merge queue with a policy that doesn’t require a person’s approval, a change can merge without anyone acting.”

Who can use Claude Ship, and how do you turn it on? #

Organizations on Team and Enterprise plans can, for repositories on GitHub, per the docs. Those with Zero Data Retention, the HIPAA configuration or “customer-managed encryption keys” cannot. Anthropic’s launch post of 23 Nov 2026 says eligible Enterprise organizations can claim “at least $10,000 in Claude Ship credits to use within 30 days of claiming” by January 15, 2027; terms apply. Checked 24 Nov 2026.

An Owner opens Organization settings > Claude Ship and turns on “one agent at a time in one repository”: Code Review, then PR Steward set to Manual (@claude steward), then a Claude Approvals policy in observe mode. A policy file on the default branch starts Approvals, so “anyone who can merge a policy file into the default branch can turn Approvals on”. A GitHub organization owner installs the Claude GitHub App.

What does the /ship command do in Claude Code? #

/ship is “a Claude Code command that opens a GitHub pull request for your change if your branch doesn’t have one”, per the /ship docs. Claude reviews the change with /code-review, then works on failing checks, conflicts and comments. The last step: “once the pull request is ready, merge it yourself”. /steward skips the review.

Unlike the GitHub agents, it runs “from the Claude Code CLI in a terminal” in your local clone, and “Cloud sessions don’t have them.” It uses your gh and git logins, so “its work on GitHub appears under your name”, and it runs in your session, so it “counts against your usage”. PR Steward “acts as the Claude GitHub App and bills your organization.” It needs Claude Code v2.1.330 or later. The page warns: “Run a watch only where you trust everyone who can merge to the base branch or push to your branch.”

What should you watch for? #

“Each agent is billed on token usage through your organization’s usage credits, separately from your plan’s included usage,” per the docs, and turning off usage credits does not stop one that is on. PR Steward “has no spend limit of its own until you set one”. An Owner sets its monthly limit and, for each repository, a spend cap in US dollars; at the cap it stops on that pull request, and “Spend can pass the cap before it stops,” per PR Steward setup. It can be on in up to 256 repositories, checked 24 Nov 2026.

  • Observe mode is billed. Approvals “has no base charge”, but its classifiers and the Code Reviews a policy starts are billed, “even in observe mode,” per the launch post.
  • Claude can approve with no review. A rule with claude: approves “starts no Code Review by itself”, per the Approvals docs.
  • A policy file can stop automatic reviews. They “normally stop where no matching rule names” claude/code_review, the docs say.
  • AI can miss things. The docs say “Claude Ship uses AI and may miss bugs, security vulnerabilities, or other issues.”

FAQ

Is Claude Ship free?

No. Each agent is billed on token usage through your organization's usage credits, separately from your plan's included usage, per Anthropic's docs, checked 24 Nov 2026. Claude Approvals has no base charge, but its classifier runs and the Code Reviews a policy starts are billed, even in observe mode.

Which plans include Claude Ship?

Team and Enterprise, for repositories on GitHub. Code Review is generally available; PR Steward and Claude Approvals are in public beta. The agents are not available with Zero Data Retention, the HIPAA configuration or customer managed encryption keys.

Can Claude Ship merge a pull request by itself?

PR Steward is designed not to approve or merge pull requests. Claude Approvals can post an approving review where your policy allows it, and a GitHub branch rule can count that review as the approval. The docs say "Your settings and GitHub branch rules determine what merges."

How is /ship different from PR Steward?

/ship runs in your own Claude Code session in a terminal, its work appears under your name, and it counts against your usage. PR Steward is turned on by an Owner, works in a cloud session as the Claude GitHub App, and bills your organization.

Do I need Claude Code to use Claude Ship?

No. Anthropic's product page says "Using Claude Ship does not require using Claude Code." The local /ship command is the part that runs in Claude Code.
