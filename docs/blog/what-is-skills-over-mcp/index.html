What is Skills over MCP? Plus MCP Tasks and Elicitation

Skills over MCP lets an MCP server ship skills with its tools. What it is, plus MCP Tasks, Elicitation and File Uploads, who gets them, and the docs.

MD Chaitanya Giri · Nov 25, 2026 · 5 min read Concepts

Skills over MCP lets an MCP server publish skills alongside its tools, so Claude learns how to do a job with them, not only what they are. Anthropic put it in public beta in Claude and Claude Code on 24 Nov 2026, with Tasks and Elicitation generally available. Checked 25 Nov 2026.

If you run AI agents, Munder Difflin is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. Its agents run on engines such as Claude Code, Codex and Gemini CLI. The install guide covers setup.

What is Skills over MCP? #

It lets servers “publish skills alongside their tools to help Claude take on longer, multi-step work,” per Anthropic’s article of November 24, 2026. “Claude loads a skill only when it’s needed, keeping context use low. Skills update with the server, so developers can ship tools and guidance together and users have nothing separate to install.”

Skills “can cover best practices, step-by-step workflows, or even playbooks tailored to a user’s account or organization,” the article says. It names Shopify, HubSpot and Atlassian as users, with Carta “coming soon”.

Underneath, “A skill is a directory containing a SKILL.md file and optional supporting files, following the Agent Skills specification,” per the MCP Skills extension docs. The news came as MCP “turns two years old this week”, per the MCP blog of 24 Nov 2026.

How is it different from tool descriptions and skills you install? #

A skill carries the how. “Tool names and descriptions tell Claude what a server can do, but don’t cover how to handle specific use cases,” Anthropic’s article says.

Skills you install yourself have their own post, Claude Code Skills. An MCP skill comes with the server, and “Servers can change skills at any time,” the Claude Code MCP docs warn. In Claude Code its name is <server>:<skill>, so a pdf skill on a server named docs is docs:pdf, and /docs:pdf report.pdf runs it on report.pdf. In Manual mode you see a prompt before one loads, and Allow this version skips it “until the server changes the skill’s files.”

What do MCP Tasks do? #

Tasks let a server run slow work without making Claude wait. “Tool calls used to have to finish before Claude could move on. With Tasks, servers can run operations that take time, or even full agent loops, while Claude keeps working and picks up the result when it’s ready,” per Anthropic.

Servers “return a durable handle instead of blocking, so clients can poll for progress,” say the Tasks extension docs. In Claude Code, an MCP task is “a long job, such as a report export or a build”, and it needs v2.1.304 or later, per the Claude Code MCP docs.

What does MCP Elicitation do? #

“Some actions need a user’s sign-off, like spending money or deleting data. With Elicitation, a server can pause to ask the user for input through a form or link, then continue where it left off,” Anthropic writes. GitHub, for one, “has users enter a repository’s name before an agent deletes it.”

The Elicitation spec has a form mode and a URL mode, and the user can accept, decline or cancel. Servers “MUST NOT use form mode elicitation to request sensitive information such as passwords, API keys, access tokens, or payment credentials.”

What will File Uploads do? #

“Claude will be able to pass files to MCP servers, not just text,” per Anthropic. “The File Uploads extension sends PDFs, spreadsheets, and images to a server without passing them through the context window.” It is “rolling out soon”, with no date given.

Its GitHub repo calls it an “Experimental MCP extension” and says: “It is not part of the MCP specification and has not been proposed as a SEP. Expect breaking changes while the working group iterates.”

Who can use them, and where? #

Skills over MCP is “in public beta in Claude and Claude Code, on by default for Pro, Max, and Ultra plans and available to Team plans once an admin enables it. Coming soon to Enterprise,” per Anthropic on 24 Nov 2026. Tasks and Elicitation “are now generally available in Claude and Claude Code for Pro, Max, and Ultra plans, and rolling out to Team and Enterprise organizations.” File Uploads “is rolling out soon in Claude and Claude Code to Pro, Max, Ultra, and eligible Team and Enterprise plans.”

In Claude Code, MCP skills need v2.1.331 or later, and cloud sessions and claude -p don’t support them, per the docs. The docs add that with /login on a Team or Enterprise plan “they’re off until your organization turns them on”; Anthropic’s article still lists Enterprise as coming soon.

Anthropic says these features “are part of the open MCP spec and its extensions, so a server that supports them works in any compatible client, not just Claude.” Elicitation is in the MCP spec itself; Skills and Tasks are extensions, and File Uploads is an experimental extension outside the spec, per its repo. For Skills, the MCP docs say “SDK and host support is still being implemented”; for Tasks, “Host support varies by client.”

How does a server author add support? #

For Skills, “Servers that support Skills MUST declare both the resources capability and the io.modelcontextprotocol/skills extension in server/discover,” per the Skills extension docs:

{
  "capabilities": {
    "resources": {},
    "extensions": {
      "io.modelcontextprotocol/skills": {
        "directoryRead": true
      }
    }
  }
}

Those servers “MUST implement skills/list and skills/get. Skill files are served through resources/read.”

For Tasks, the Tasks docs say to advertise io.modelcontextprotocol/tasks in server/discover, answer a long request with resultType: "task" and a taskId, and serve tasks/get. The Claude Code docs add: “Answer with a task only when the request carries the extension, or the call fails with the tool error Unsupported result type 'task' for tools/call.”

FAQ

What is Skills over MCP?

A way for an MCP server to publish skills alongside its tools, so Claude gets guidance on how to handle a job, not only a list of tools. Claude loads a skill only when it is needed. Anthropic put it in public beta in Claude and Claude Code on 24 Nov 2026.

What are MCP Tasks?

An MCP extension that lets a server answer a slow tool call with a task handle instead of blocking. Claude keeps working and picks up the result when it is ready. What is MCP elicitation?

Part of the MCP spec that lets a server pause a call and ask the user for input, through a form or a URL. The spec says servers must not use form mode to ask for passwords, API keys, access tokens or payment credentials.

Does Skills over MCP only work in Claude?
