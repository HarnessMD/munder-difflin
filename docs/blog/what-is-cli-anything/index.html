What is CLI-Anything? A Command Line for Any App, for AI Agents

CLI-Anything (HKUDS/CLI-Anything) gives AI agents a command line for existing software. What it is, how CLI-Hub works and how to install it.

MD Chaitanya Giri · Nov 26, 2026 · 5 min read Concepts

CLI-Anything is an open source project that gives AI agents a command line for existing software, so they can drive apps like GIMP, Blender and LibreOffice with commands instead of clicks. Its README pairs a CLI generator with CLI-Hub, a registry of CLIs. It comes from HKUDS under the Apache 2.0 licence. Checked 26 Nov 2026.

If you run AI agents, Munder Difflin is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. Its agents run on engines such as Claude Code, Codex and Gemini CLI, and can use skills, MCP servers and plugins. The install guide covers setup.

What is CLI-Anything? #

CLI-Anything turns software built for people into tools an agent can run from a terminal. The README calls it “Bridging the Gap Between AI Agents and the World’s Software” and says: “Make any software agent-ready for Pi, OpenClaw, nanobot, Cursor, Claude Code, etc.” Each CLI it builds is called a harness.

It is both a generator and a hub. The README says it “has two equally useful starting points”: install cli-anything-hub to “Use the existing CLI ecosystem now”, or install the plugin or skill for your agent to “Build a new agent-native CLI”. Software it names includes GIMP, Blender, LibreOffice, Zotero and FreeCAD, among many others.

How does CLI-Anything work? #

You point your agent at a program’s source code or repo, and it builds a Python CLI in seven phases, per the README:

  1. Analyze: “Scans source code, maps GUI actions to APIs”.
  2. Design: command groups, a state model and output formats.
  3. Implement: a Click CLI with a REPL, JSON output, and undo and redo.
  4. Plan tests in a TEST.md file.
  5. Write the tests.
  6. Document the results.
  7. Publish: create setup.py and install the CLI to your PATH.

The CLI calls the real program rather than copying it: “We build structured interfaces TO software, not replacements.” So LibreOffice still makes the PDFs and Blender still renders the 3D scenes. Each CLI also gets a SKILL.md with a name and description “for agent skill discovery”, the same idea as Claude Code Skills: What They Are, Where They Live and How to Write One. By the project’s own figures, read 26 Nov 2026, the README badge shows 2,461 tests passing, while its test summary totals 2,464.

The README names three limits. It “relies on frontier-class models (e.g., Claude Opus 4.6, Claude Sonnet 4.6, GPT-5.4)”, and weaker or smaller models “may produce incomplete or incorrect CLIs”. When the software only provides compiled binaries that require decompilation, “harness quality and coverage will degrade substantially”. And one run may not cover everything: “Running /refine one or more times is often needed”.

How do you install and use CLI-Anything? #

There are two routes: install CLIs that already exist, or build a new one. For existing CLIs, the README starts with:

pip install cli-anything-hub
# Browse what is available
cli-hub list
cli-hub search image

# Install and try a CLI immediately
cli-hub install gimp
cli-hub info gimp
cli-hub launch gimp

It warns: “If a selected CLI needs GIMP, Blender, LibreOffice, or another upstream tool, install that upstream application too.”

To build a new CLI you need Python 3.10+ and a supported AI coding agent. In Claude Code, the README gives:

# Add marketplace & install (recommended)
/plugin marketplace add HKUDS/CLI-Anything
/plugin install cli-anything

# Build a CLI for any software with a codebase
/cli-anything <software-name>

Its example is /cli-anything ./gimp. The README also has install steps for Cursor, Pi, OpenClaw, OpenCode, Codex, Hermes, Reasonix, Qodercli and GitHub Copilot CLI, and Goose can run the same commands through a CLI provider such as Claude Code. It marks OpenCode, Goose, Codex, Hermes and Reasonix as Experimental.

Then the agent uses the CLI like any other command. Per the README, “the generated CLI works the same way” whichever agent built it:

# Install to PATH
cd gimp/agent-harness && pip install -e .

# Use from anywhere
cli-anything-gimp --help
cli-anything-gimp project new --width 1920 --height 1080 -o poster.json
cli-anything-gimp --json layer add -n "Background" --type solid --color "#1a1a2e"

# Enter interactive REPL
cli-anything-gimp

Agents “discover capabilities via standard --help and which commands”, and a --json flag on every command returns structured data.

What is CLI-Hub? #

CLI-Hub is the project’s catalogue of CLIs, at clianything.cc. The site calls it “an agent-friendly registry and package manager for CLI tools”. It lists CLI-Anything CLIs and Public CLIs, which it says “remain the property of their respective software owners and maintainers”.

The README’s meta skill lets agents “discover and install the right CLI for a task”, and it names OpenClaw, Nanobot, Claude Code, Codex, Reasonix and Antigravity:

npx skills add HKUDS/CLI-Anything --skill cli-hub-meta-skill -g -y

Then you prompt: “Find appropriate CLI software in CLI-Hub and complete the task: …”

Release v0.4.0, out on 25 Jun 2026, added matrices, bundles of CLIs for a whole workflow, found with cli-hub can <task>. The pricing page, read 26 Nov 2026, says “CLI-Anything and CLI-Anything Hub are open source and free to use”, though some third party CLIs, APIs or apps in the registry “may have their own pricing”.

Why a command line instead of a browser or screen clicks? #

The README’s answer is reliability: “No screenshots, no clicking, no RPA fragility. Pure command-line reliability with structured interfaces”. Its list of reasons says text commands “match LLM format”, --help flags give “automatic documentation agents can discover”, and JSON output “eliminates parsing complexity”. The project’s technical report on arXiv, dated 2 Jun 2026, adds that current GUI agents “struggle with brittle pixel-level interactions, timing dependencies, and coordinate-based actions that break with interface changes.”

Our view: a command line suits work an agent repeats, because a fixed command is easier to check than a click on a moving screen. A browser still fits sites with no CLI, and the README’s own table lists a browser CLI, cli-anything-browser. For more, read Why CLI Agents Are So Powerful and Browser Use Alternatives: 5 Picks After the 1.0 Rewrite (Nov 2026).

FAQ

What is CLI-Anything?

An open source project from HKUDS, under the Apache 2.0 licence, whose README is titled "CLI-Anything: Making ALL Software Agent-Native". It has two parts: a generator that builds a command line for a piece of software, and CLI-Hub, a registry of CLIs you can install. Checked 26 Nov 2026.

How do I install CLI-Anything in Claude Code?

Per the README, run `/plugin marketplace add HKUDS/CLI-Anything`, then `/plugin install cli-anything`, then `/cli-anything <software-name>` to build a CLI. To install CLIs that already exist, run `pip install cli-anything-hub`, then `cli-hub install <name>`.

What is CLI-Hub?

CLI-Hub, at clianything.cc, is the project's catalogue of CLIs. The site calls it "an agent-friendly registry and package manager for CLI tools". The `cli-hub` command can list, search, inspect, install, update, uninstall and launch them.

Which agents does CLI-Anything work with?

For building CLIs, the README names Claude Code, Cursor, Pi, OpenClaw, OpenCode, Codex, Hermes, Reasonix, Qodercli and GitHub Copilot CLI, plus Goose through a CLI provider. Its CLI-Hub skill names OpenClaw, Nanobot, Claude Code, Codex, Reasonix and Antigravity.

Is CLI-Anything free?

Yes. Its pricing page, read 26 Nov 2026, says "CLI-Anything and CLI-Anything Hub are open source and free to use." It adds that some third party CLIs, APIs or apps in the registry may have their own pricing.
