What is Superpowers? The skills library for coding agents

Superpowers (obra/superpowers) is an open source skills library that gives coding agents a set workflow. What is inside, how to install it, its limits.

MD Chaitanya Giri · Nov 24, 2026 · 5 min read Concepts

Superpowers is “a complete software development methodology for your coding agents, built on top of a set of composable skills and some initial instructions that make sure your agent uses them”, per its README. It is open source under the MIT licence, at obra/superpowers on GitHub. Checked on 24 Nov 2026.

The README says “It’s not uncommon for your agent to work autonomously for a couple hours at a time”. We think runs that long make usage limits worth planning for; see How to Get the Most Out of Your Claude Code Max Plan.

If you run AI agents, Munder Difflin is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. Its agents run on engines such as Claude Code, Codex and Gemini CLI. The install guide covers setup.

What is Superpowers? #

Superpowers is a set of skills plus starting instructions that make a coding agent use them. Per the README, “because the skills trigger automatically, you don’t need to do anything special. Your coding agent just has Superpowers.”

In Claude Code it installs as a plugin. Anthropic’s plugin docs define a plugin as “a directory of skills, agents, hooks, MCP servers, or other components that Claude Code installs and loads as one unit”. A skill, per the skills docs, is a SKILL.md file with instructions, and “Claude uses skills when relevant”.

What is inside Superpowers? #

The README groups 15 skills under four headings: Testing, Debugging, Collaboration and Meta. On 24 Nov 2026 the repo’s skills folder held the same 15 folders.

Group Skills
Testing test-driven-development
Debugging systematic-debugging, verification-before-completion, diagnosing-superpowers
Collaboration brainstorming, writing-plans, executing-plans, dispatching-parallel-agents, requesting-code-review, receiving-code-review, using-git-worktrees, finishing-a-development-branch, subagent-driven-development
Meta writing-skills, using-superpowers

In the README’s own words, brainstorming is “Drawing out intent before building”, test driven development is the “RED-GREEN-REFACTOR cycle”, systematic debugging is a “4-phase root cause process”, and writing skills lets you “Create new skills following best practices”.

How do you install Superpowers? #

You install it once for each agent you use. “Installation differs by harness”, the README says, and “If you use more than one, install Superpowers separately for each one.” It gives steps for 16 harnesses.

In Claude Code, install from Anthropic’s official marketplace:

/plugin install superpowers@claude-plugins-official

Or register the Superpowers marketplace, then install from it:

/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

For the other harnesses, the README gives these steps, with commands word for word:

How does Superpowers work in a session? #

It makes the agent ask before it codes: per the README, it “steps back and asks you what you’re really trying to do.” The basic workflow has seven steps, each a skill:

  1. Brainstorming (brainstorming): questions about what you want, then a design you approve.
  2. Worktree (using-git-worktrees): an isolated workspace on a new branch, with a “clean test baseline”.
  3. Plan (writing-plans): “bite-sized tasks (2-5 minutes each)”, each with “exact file paths, complete code, verification steps”.
  4. Subagents (subagent-driven-development or executing-plans): “a fresh subagent per task with a review after each”, or every task inline with one review of the whole branch at the end.
  5. Tests (test-driven-development): “RED-GREEN-REFACTOR”, and it “Deletes code written before tests.”
  6. Review (requesting-code-review): between tasks; “Critical issues block progress.”
  7. Finish (finishing-a-development-branch): verifies tests, then offers merge, PR, keep or discard.

The README adds: “The agent checks for relevant skills before any task.” It calls these “Mandatory workflows, not suggestions.”

Who makes Superpowers, and under what licence? #

Jesse Vincent and Prime Radiant make it, under the MIT licence. The README says Superpowers “is built by Jesse Vincent and the rest of the folks at Prime Radiant”. At 16:24 UTC on 24 Nov 2026 the GitHub API showed obra/superpowers created on 9 Oct 2025, with 325,716 stars and v7.0.2, released 3 Nov 2026, as its latest release.

Vincent’s release post of 9 Oct 2025 says: “Anthropic released Claude’s new plugins system this morning and it seemed like the right impetus to ship.”

What should you watch for with Superpowers? #

The README names these limits:

  • Updates vary. “Superpowers updates are somewhat coding-agent dependent, but are often automatic.”
  • Restarts. Restart active Hermes and Muse sessions after installing. On Hermes, “a very long session that compacts over its first turn loses the bootstrap”, so start a fresh session if skills stop triggering.
  • Sessions can misbehave. A skill can fire “when it shouldn’t”, or the agent can burn “more tokens than you’d expect”. Ask your agent to “figure out what went wrong with superpowers in this session” and it runs diagnosing-superpowers.
  • Optional telemetry. The Prime Radiant logo in brainstorming’s optional visual companion loads from Prime Radiant’s website and includes the Superpowers version. Set SUPERPOWERS_DISABLE_TELEMETRY to any true value to stop it.
  • Skill contributions. The README says “we don’t generally accept contributions of new skills”, and any skill update “must work across all of the coding agents we support”.

FAQ

Is Superpowers open source?

Yes. The code is on GitHub at obra/superpowers under the MIT licence, per the GitHub API and the README, checked 24 Nov 2026.

Which coding agents does Superpowers work with?

The README gives install steps for 16 harnesses: Claude Code, Antigravity, Codex App, Codex CLI, Cursor, Devin CLI, Factory Droid, Gemini CLI, GitHub Copilot CLI, Grok Build CLI, Kimi Code, OpenCode, Pi, Qwen Code, Hermes Agent and Muse. It says to install Superpowers separately for each one you use.

How do I install Superpowers in Claude Code?

Per the README, run `/plugin install superpowers@claude-plugins-official` to install it from Anthropic's official marketplace. Or register the Superpowers marketplace with `/plugin marketplace add obra/superpowers-marketplace`, then run `/plugin install superpowers@superpowers-marketplace`.

Does Superpowers send telemetry?

Only through an optional feature. The README says the Prime Radiant logo on brainstorming's optional visual companion loads from Prime Radiant's website and includes the Superpowers version, not your project or prompt. Setting `SUPERPOWERS_DISABLE_TELEMETRY` to any true value turns it off.

Who makes Superpowers?

Jesse Vincent and the rest of the folks at Prime Radiant, per the README. He announced it on his blog on 9 Oct 2025, the day the GitHub repo was created.
