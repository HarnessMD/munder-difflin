Agent Tools Today, 3 Nov 2026: Astra Edits Weights, Claude Code 2.1.317, Momentic Mo

The top launches, skills, multi agent moves, rising repos and arguments in AI agents from 2 to 3 Nov 2026, each with its source and date.

MD Chaitanya Giri · Nov 3, 2026 · 5 min read News

Agent tools today, 3 Nov 2026, in one line: an MIT CSAIL post says GPT-6 Astra can read and rewrite network weights, Claude Code 2.1.317 shipped, and Momentic launched Mo, its QA agent. It covers 2 Nov 16:00 UTC to 3 Nov 04:00 UTC, checked 3 Nov. The previous edition is 2 Nov.

Top 3 launches #

  1. Momentic Mo. Its founders describe “QA agents that autonomously plan, explore, and bug-bash controls and user flows” in web, iOS and Android apps. In their 60 minute test on four open source apps with 1,396 human labeled bugs, Mo found 269 bugs, Codex 86, Claude Code 59 and Devin 27. These are the vendor’s own figures from 2 Nov, judged by an LLM with a human reviewer; Codex was a little more precise, 86% against 84%, and cost $0.80 per bug against $2.67 for Mo. 131 points on Hacker News on 3 Nov. Source
  2. Tucano. “Your team of AI agents, on your computer. Your rules.” Agents talk in channels and hand work to each other, running on the Claude Code, Codex, Cursor CLI, OpenCode or Pi you already have. Merges, purchases, posts, emails and deletes “become an approval tied to the exact action”, says the README. Apache 2.0, created 28 Oct, 139 stars on 3 Nov. Source
  3. Pi-Remote. A companion for the pi agent that can “mirror a live session to the browser, view it, send messages, and run commands remotely”. It attaches through pi’s official extension API and “does not modify pi’s source code”. Its description says the link is encrypted end to end. MIT, created 28 Oct, 272 stars on 3 Nov. Source

Top 3 skills, MCP servers and plugins #

  1. Video Studio Skill. A “Claude Code skill for product videos: real browser capture, branded composition, and local mastering”, using Playwright CLI, HyperFrames and FFmpeg. The README says its demo “stops before capture and rendering”. MIT, version 1.0.1, 70 points on Hacker News and 201 stars on 3 Nov. See Claude Code skills. Source
  2. Skills For Real Engineers. Matt Pocock’s “agent skills that I use every day to do real engineering”, which he says are “designed to be small, easy to adapt, and composable”. In Claude Code it installs with claude plugin install mattpocock-skills@claude-plugins-official. MIT, more than 310,000 stars, and 858 stars in a day on GitHub trending on 3 Nov. Source
  3. ai-design-check. “95 design rules, a checker with no dependencies and no API key, and an agent skill that repairs the screen.” It reads web projects and SwiftUI and Jetpack Compose apps; the check runs with npx @enmera/ai-design-check. MIT, created 28 Oct, 201 stars on 3 Nov. Source

Top 4 moves from multi agent tools #

  1. Claude Code 2.1.317. Published 3 Nov at 01:25 UTC. It adds “a check that asks before a web or shell tool call sends your account email address to the network”, and onFailure: "block" for Agent SDK hook callbacks. It fixes “project and local MCP servers disconnecting after the first turn in some Claude desktop sessions”, and “Ctrl+C stopping all running background agents when pressed to clear typed text at the prompt”. See Claude Code Max plan tips. Source
  2. Qwen Code 0.26.6. Published 2 Nov at 18:22 UTC. The Web Shell gets a sidebar activity view and an “Add to Split View” option. MCP tool discovery “now skips duplicate tool names but keeps all uniquely named tools”, so one name clash no longer hides a whole server. Source
  3. GitHub Copilot CLI 1.0.106-5. The last of three pre releases between 2 Nov 20:08 UTC and 3 Nov 01:13 UTC. 1.0.106-3 added “opt-in session management tools and @mentions for opted-in local sessions”; this one honours includeCoAuthoredBy: false in ACP mode. Source
  4. T3 Code nightly 0.1.7. A nightly, published 3 Nov at 02:27 UTC. Its notes lead with “Kiro (beta). Use Kiro as a provider in T3 Code.” and add Cursor limits and usage after a Cursor sign in. T3 Code also took 3,229 stars in a day on GitHub trending on 3 Nov. Source

Top 3 rising repos #

  1. agent-desktop. From Vercel Labs: “Computer use for AI agents: read and operate desktop apps through the OS accessibility tree.” Its README warns that snapshots “can contain private desktop content”. Apache 2.0, more than 10,000 stars, and 2,275 stars in a day on GitHub trending on 3 Nov. Source
  2. claude-mem. Its GitHub description: “Captures everything your agent does during sessions, compresses it with AI, and injects relevant context back into future sessions.” Apache 2.0, more than 110,000 stars, and 1,803 stars in a day on GitHub trending on 3 Nov. See long term memory for Claude Code. Source
  3. Paperclip. “Open-source orchestration for teams of AI agents”, with a waitlist for a Paperclip Cloud. MIT, more than 110,000 stars, and 412 stars in a day on GitHub trending on 3 Nov. Source

Stars can rise for reasons other than use: names to watch, not picks.

Top 2 things people are arguing about #

  1. Can a model fix a network by editing its weights? Rikiya Takehi and three other MIT CSAIL authors wrote on 2 Nov that “frontier LLMs are surprisingly good at natively reading and writing neural network weights”. In their example, dated 2 Nov 2026, GPT-6 Astra edited 0.016% of the weights of Qwen3.5-0.8B with no gradients, and MATH-500 rose from 7.9% to 48.1%. These are the authors’ own figures. They also say one edit, “In a single try with no tools”, made a stuck car policy succeed in all 1,024 episodes. More than 2,100 points and 680 comments on Hacker News on 3 Nov. Source
  2. Should the SEC block Anthropic’s IPO? Matt Scherer argues in TechPolicy.Press on 2 Nov that it should. He cites “at least $582 billion in non-cancelable spending commitments to just five companies” and says the 2026 results “have not been subjected to formal auditing”. CNBC reports, from the amended S-1 filed 2 Nov, about $17 billion in third quarter revenue, growth of about 47% on the quarter against 144% in Q2, and about $895.4 billion in purchase commitments. 239 points for the opinion piece and 228 for CNBC’s report on Hacker News on 3 Nov. Source

How this list is built #

For this edition we read the GitHub releases of tracked tools, GitHub trending and the Hacker News front page, and opened every page linked above. No item here comes from X or Reddit. A name only makes a list with an opened link and a signal: points, stars or a dated release. Repos are checked against the GitHub API first. Nightlies appear only when the notes carry a change a user would notice.
