# Asset attribution

This repository ships no third-party pixel art.

- `resources/themes/plain` is generated by `scripts/theme-packs/plain/gen_pack.py` from flat
  geometric tiles (MIT, like the rest of the code).
- Characters and portraits are drawn procedurally in `scene/office/portraitArt.ts` (MIT).
- `fonts/` holds the web fonts listed in `fonts/LICENSE.txt`.

Theme packs you install yourself keep their own licences; put credit in the pack's `theme.json`
`license` field.
