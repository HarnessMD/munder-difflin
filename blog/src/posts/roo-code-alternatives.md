## What was Roo Code?

Roo Code was a free, open source AI coding agent for VS Code that worked with almost any model. Its [docs](https://docs.roocode.com), read 4 Nov 2026, say it is "compatible with dozens of providers and hundreds of models". The [providers page](https://roocodeinc.github.io/Roo-Code/providers/) lists Anthropic, OpenAI, Google Gemini, DeepSeek, OpenRouter and Ollama, among others.

The [README](https://github.com/RooCodeInc/Roo-Code) lists five modes: Code, Architect, Ask, Debug and Custom Modes. The [FAQ](https://roocodeinc.github.io/Roo-Code/faq) says "The Roo Code extension is free and open-source", and you paid your model provider per token. The licence is Apache 2.0, per the GitHub API.

## Is Roo Code shut down?

Yes. Its README, read 4 Nov 2026, says: "The Roo Code Extension was shut down on May 15th." The GitHub API shows the repository archived, with its last push and final release, v3.54.0, on 15 May 2026.

No Roo Code Cloud pricing page is left to check: roocode.com redirects to [roomote.dev](https://roomote.dev/). The README now reads like a forwarding address, naming ZooCode and Cline. Our view: move before a model or VS Code update breaks it. The full story is in [what is Roo Code](/blog/what-is-roo-code/).

## 1. ZooCode: if you want Roo Code to keep going

ZooCode is the closest swap: the same extension, new maintainers. Its [README](https://github.com/Zoo-Code-Org/Zoo-Code), read 4 Nov 2026, says it "continues development of this project after the Roo team wound down active Roo Code work to focus on Roomote". It keeps the five modes, is Apache 2.0, and shipped v3.94.0 on 31 Oct 2026.

The [migration guide](https://docs.zoocode.dev/roo-to-zoo-migration) is two steps: export your Roo Code settings, then import the file. It warns: "The exported file can include sensitive settings, including API keys." The [pricing page](https://www.zoocode.dev/pricing) lists Free at $0 with your own keys, and Team at $25 per seat a month, on 4 Nov 2026.

## 2. Munder Difflin: if you want a team, not one agent in one editor

[Munder Difflin](https://harnessmd.com/download) is what we make, a team of AI agents on your own computer. It runs on engines such as Claude Code, Codex and Gemini CLI, and connects tools through MCP servers, skills and plugins. Agents run while your computer runs. A Cloud Office and a mobile app are coming soon. Setup is in [how to install and use Munder Difflin](/blog/how-to-install-and-use-munder-difflin/).

## 3. Cline: if you want the project Roo Code came from

Cline is where Roo Code started: Roo Code's README calls it the project "from where Roo Code originated". Cline's [README](https://github.com/cline/cline), read 4 Nov 2026, offers a VS Code extension, a JetBrains plugin, a CLI and a desktop app for macOS and Windows. It is Apache 2.0 and shipped v4.1.26 on 26 Oct 2026.

Its [pricing page](https://cline.bot/pricing), read 4 Nov 2026, says "Cline is free for individual developers" and you pay only for inference. That page lists the JetBrains extension under Enterprise. More options are in [Cline alternatives](/blog/cline-alternatives/).

## 4. Kilo Code: if you want more editors and a CLI

Kilo Code began as a Roo fork; [Kilo's migration guide](https://kilo.ai/articles/roo-to-kilo-migration-guide), read 4 Nov 2026, says "We started Kilo as a Roo fork in 2025." Its [README](https://github.com/Kilo-Org/kilocode) covers VS Code, JetBrains and a CLI, offers "500+ models", and says you "pay the model provider's rate with zero markup". It is MIT licensed; the latest stable release was v7.8.18 on 26 Oct 2026.

The guide is frank: "What breaks: API key storage, Orchestrator mode, codebase indexing." In return it lists "parallel subagents, an Agent Manager with git worktrees". We set it against Cline in [Kilo Code vs Cline](/blog/kilo-code-vs-cline/).

## 5. Roomote: if you want to follow the Roo team to the cloud

Roomote is where the Roo team went; Kilo's guide gives the stated reason as a "Pivot to Roomote, Roo's cloud agent". The [Roomote homepage](https://roomote.dev/), read 4 Nov 2026, calls it "The cloud coding agent you actually own", self hostable or hosted by them.

Self hosted pricing on that page, 4 Nov 2026: free for up to 10 users, $249 a month for 11 to 50 users and $499 a month for 51 to 100. "You pay your infrastructure and inference providers directly." The [LICENSE file](https://github.com/RooCodeInc/Roomote/blob/develop/LICENSE) is the Fair Core License, FCL-1.0-ALv2, and v1.20.0 shipped on 4 Nov 2026. We think that is a different deal from Apache 2.0, so read it first.

## 6. Claude Code: if you want a first party agent

Claude Code is Anthropic's own agent, and its [overview](https://code.claude.com/docs/en/overview), read 4 Nov 2026, says it is "Available in your terminal, IDE, desktop app, and browser." The [LICENSE file](https://github.com/anthropics/claude-code/blob/main/LICENSE.md) says "All rights reserved". It shipped v2.1.318 on 4 Nov 2026.

[Anthropic's pricing page](https://claude.com/pricing), read 4 Nov 2026, leaves Claude Code out of Free and includes it in Pro at $17 a month billed annually or $20 monthly. See [what Claude Code costs](/blog/how-much-does-claude-code-cost/).

## Which one should you pick?

Our view: ZooCode if you want your modes and settings back today. Munder Difflin if you want several agents on research, writing, ops and coding at once. Cline or Kilo Code for a larger project with a CLI and JetBrains. Roomote if your team wants cloud agents and accepts its licence. Claude Code if you already pay Anthropic.
