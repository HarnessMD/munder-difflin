## Why look for a Pi agent alternative?

Our view: people look past Pi when they want features in the box rather than features they build. Pi's [README](https://github.com/earendil-works/pi), read on 26 Oct 2026, is clear about the trade:

- **Small on purpose.** It calls Pi "a minimal, extensible agent harness that you can make your own", and says it "skips features like sub-agents and plan mode". You add them with extensions or packages.
- **No permission system.** In its words: "Pi does not include a built-in permission system for restricting filesystem, process, network, or credential access." It runs with your user's permissions and points to containers or a sandbox for limits.
- **Terminal and code.** Pi works in the terminal, in print or JSON mode, over RPC and through a TypeScript SDK. Chat apps, schedules and work beyond code need something else.

None of this is a flaw for people who like to build their own agent. Pi is MIT licensed, and release v1.4.0 shipped on 21 Oct 2026.

## Which Pi agent alternatives are worth a look?

Seven tools pass, each live with a release in October 2026.

**1. OpenCode.** [OpenCode](https://github.com/anomalyco/opencode) is "The open source AI coding agent", MIT licensed, in the terminal and as a desktop app in beta, with release v1.19.4 on 22 Oct 2026. Its [site](https://opencode.ai) lists "75+ LLM providers", local models included, and says "OpenCode is 100% free to use" (26 Oct 2026). Best for: a fuller open source agent on any model. See [OpenCode alternatives](/blog/opencode-alternatives/).

**2. Munder Difflin.** Keep Pi and add more agents. [Munder Difflin](https://github.com/HarnessMD/munder-difflin) is MIT licensed and runs Pi as one of its CLIs, next to Claude Code, Codex, OpenCode, Gemini CLI and Copilot. Each agent gets its own terminal, and they share a task board; the [install guide](/blog/how-to-install-and-use-munder-difflin/) covers setup. Best for: a team of agents for research, writing, ops and code.

**3. Claude Code.** Anthropic's agent "reads your codebase, edits files, runs commands, and integrates with your development tools", per its [docs](https://code.claude.com/docs/en/overview). It runs Claude models and has permission modes built in. [Anthropic's pricing page](https://claude.com/pricing) includes it in Pro, $20 if billed monthly, as of 26 Oct 2026. Best for: Claude with permissions built in.

**4. Codex CLI.** [Codex CLI](https://github.com/openai/codex) is "a coding agent from OpenAI that runs locally on your computer", Apache 2.0. On ChatGPT plans the CLI starts at Plus, $20 a month, per OpenAI's [Codex pricing page](https://learn.chatgpt.com/docs/pricing) on 26 Oct 2026. Best for: people who already pay for ChatGPT. See [Codex alternatives](/blog/codex-alternatives/).

**5. Hermes Agent.** [Hermes Agent](https://github.com/NousResearch/hermes-agent) is "The self-improving AI agent built by Nous Research", MIT licensed, release v0.22.5 on 23 Oct 2026. Its README says "Use any model you want", lists a built in cron scheduler and subagents, and runs in Telegram, Discord, Slack, WhatsApp, Signal and the CLI. Best for: an agent that lives in your chat apps. See [what is Hermes Agent](/blog/what-is-hermes-agent/).

**6. Goose.** [Goose](https://github.com/aaif-goose/goose) is "a general-purpose AI agent that runs on your machine", as a desktop app and a CLI, and "works with 15+ providers", Ollama included. Apache 2.0, release v1.56.0 on 23 Oct 2026. Best for: one agent for code and other work.

**7. Crush.** [Crush](https://github.com/charmbracelet/crush) from Charm is a terminal agent that lets you "switch LLMs mid-session while preserving context" and add tools through MCP. It uses the Functional Source License 1.1 with an MIT future licence, release v0.98.2 on 23 Oct 2026. Best for: a polished terminal agent with LSP context.

## Which Pi agent alternative should you pick?

Pick by what you missed in Pi.

- **OpenCode** if you want Pi's openness with more in the box.
- **Munder Difflin** if you want to keep Pi and run other agents beside it for any knowledge work, coding included.
- **Claude Code** if you want permission modes and Anthropic's models.
- **Codex CLI** if you already pay for ChatGPT.
- **Hermes Agent** for an agent you reach from chat apps, on a schedule.
- **Goose** for one agent across code and workflows, with a desktop app.
- **Crush** for a terminal agent that swaps models mid session.
