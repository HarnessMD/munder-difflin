## What is the difference between Codex and ChatGPT?

The difference is the job: ChatGPT talks and produces documents, Codex works on code with developer tools. OpenAI's [Use ChatGPT page](https://learn.chatgpt.com/docs/use-chatgpt) puts it in one line: "Use Chat for a question or back-and-forth. Turn on Work in the switcher when you want ChatGPT to carry a larger task through to a reviewable result. Select Codex when you want developer views or more technical detail, especially for software development."

So is Codex part of ChatGPT? Yes. The [desktop app page](https://learn.chatgpt.com/docs/app) tells you to "Choose ChatGPT or Codex" when you send your first message. The [pricing page](https://learn.chatgpt.com/docs/pricing) says "ChatGPT Work usage inside ChatGPT uses the same pricing, credits, and usage limits as Codex."

Codex also lives outside the app. The [Codex README](https://github.com/openai/codex) says "Codex CLI is a coding agent from OpenAI that runs locally on your computer." GitHub listed the repo under Apache-2.0 on 28 Oct 2026, with release rust-v0.165.0 published on 27 Oct.

## Do you need a ChatGPT plan to use Codex?

No, an API key works too, but a plan decides where you can use Codex. OpenAI's pricing page listed these plans, in US dollars, on 28 Oct 2026:

- **Free at $0 and Go at $8 a month (28 Oct 2026):** "GPT-6 Luna at Standard speed in the desktop app, subject to rollout".
- **Plus at $20 a month (28 Oct 2026):** "Codex on the web, in the CLI, in the IDE extension, and on iOS", automatic code review and Slack, GPT-6.1 Sol and GPT-6 Luna.
- **Pro from $100 a month (28 Oct 2026):** "Plans at $100, $200, or $500 USD per month", with Ultrafast mode on Pro $500.
- **Business at $20 per user a month (28 Oct 2026):** for two or more users billed annually, or $25 billed monthly.
- **API key:** Codex "in the CLI, SDK, or IDE extension", with "No cloud-based features", billed at API pricing.

Limits are estimates, not caps. For Plus and Standard Business, the page estimated local messages "per five-hour period": 15 to 160 on GPT-6.1 Sol and 350 to 3,000 on GPT-6 Luna. It adds that "Weekly limits may also apply" and that "Pro plans currently have no five-hour limit." [Codex pricing](/blog/codex-pricing/) has the credit rates.

## Where does each one run?

ChatGPT runs on the web, the desktop app and mobile; Codex adds your terminal, your editor and OpenAI's cloud. The desktop app comes "for macOS or Windows", with a Linux installation guide.

- **Codex CLI:** the [CLI page](https://learn.chatgpt.com/docs/codex/cli) says Codex can "inspect files, make edits, and run the tools already installed on your machine", and `codex exec` runs it in scripts and CI.
- **IDE extension:** per the [IDE page](https://learn.chatgpt.com/docs/codex/ide), "VS Code and compatible editors use the Codex extension; Xcode and JetBrains IDEs provide their own integrations."
- **Codex Cloud:** each task "has its own workspace and can keep working while your computer is asleep", according to the [cloud page](https://learn.chatgpt.com/docs/cloud).
- **Mobile:** OpenAI's [mobile page](https://learn.chatgpt.com/docs/mobile) says the ChatGPT mobile app can start, guide and approve Codex tasks that run "in the cloud or on a connected computer", with availability depending on rollout and your workspace settings.

## Which is better for coding?

Codex, for anything that touches a repository. OpenAI's [dots page](https://learn.chatgpt.com/docs/dots) lists Codex for when you want to "build, debug, test, or review software and work directly with code and developer tools". Model choice differs too: the pricing page says "GPT-6.1 Sol is available in Work and Codex, not Chat."

ChatGPT Work can still handle some code. The Use ChatGPT page says it can "Run code and shell commands, analyze data, inspect files, review code, and work with repositories your selected environment can access." The [Work page](https://learn.chatgpt.com/docs/get-started-with-work) also says that if you used Codex for non coding work, "you can stay in Codex or use ChatGPT Work instead."

Our view: Chat to think it through, Codex to change the code, Work for the write up. Same bill, three tabs.

## Pick Codex if..., pick ChatGPT if...

Pick by what you need handed back: a diff or a document.

**Pick Codex if:**
- You want an agent that edits files and runs commands in your repo.
- You want to script it in CI with `codex exec` or an API key.
- You want cloud tasks that keep going while your laptop sleeps.

**Pick ChatGPT if:**
- You want an answer, a brainstorm or a draft (Chat).
- You want a deck, report or spreadsheet you can review (Work).
- You are on Free or Go and mostly ask questions.
