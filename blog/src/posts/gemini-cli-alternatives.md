## What is Gemini CLI, and what does it cost now?

Gemini CLI (`gemini`) is Google's open source AI agent for the terminal, Apache 2.0, and for individuals it is now paid only. Its [README](https://github.com/google-gemini/gemini-cli), read 4 Nov 2026, opens with a notice: "No free tier or Google AI plans". Free individual access and Google AI Pro and Ultra "moved to Antigravity CLI on June 18, 2026". What remains is Gemini Code Assist Standard or Enterprise, Code Assist for GitHub on Google Cloud, and "legacy paid API / Vertex keys".

[Google's announcement](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/) of 19 May 2026 set that date and said Gemini CLI "will remain accessible via paid Gemini and Gemini Enterprise Agent Platform API keys." Stable [v0.67.0](https://github.com/google-gemini/gemini-cli/releases/tag/v0.67.0) shipped on 4 Nov 2026.

## Which models and quotas does Gemini CLI have?

Gemini 3 and Gemini 2.5 models, not Gemini 4. Its [model docs](https://geminicli.com/docs/cli/model/), read 4 Nov 2026, offer Auto (Gemini 3) with `gemini-3-pro-preview` and `gemini-3-flash-preview`, Auto (Gemini 2.5), or Manual. The README says it is "Not tuned for the Gemini 4 series" and sends Gemini 4 Argon users to Antigravity CLI.

The [quota page](https://geminicli.com/docs/resources/quota-and-pricing/), read 4 Nov 2026, gives 1,500 model requests per user per day on Code Assist Standard and 2,000 on Enterprise. Its table still shows 1,000 free requests a day for a personal sign in, but the banner above it says Gemini CLI "was replaced by Antigravity CLI on June 18th, 2026" for unpaid and Google One users. Trust the banner. Our guide to [installing Gemini CLI](/blog/how-to-install-gemini-cli/) covers the sign ins that still work.

## 1. Antigravity CLI: if you want to stay with Google

Our view: this is the default move, since Google built it as the successor. [Antigravity's CLI page](https://antigravity.google/product/antigravity-cli) calls it "the terminal-first surface to interact with Antigravity agents". The [pricing page](https://antigravity.google/pricing), read 4 Nov 2026, has an individual plan at $0 a month with "Basic weekly rate limits", then Google AI Pro and Ultra with more.

The [models page](https://antigravity.google/docs/models/) lists Gemini 4 Argon, Gemini 3.8 Flash and Claude models, though Argon is not on the free plan and three older models "Will be removed on November 18, 2026." The [migration guide](https://antigravity.google/docs/cli/gcli-migration) says `agy plugin import gemini` converts extensions, and workspace skills move from `.gemini/skills/` to `.agents/skills/`. More in [Claude Code vs Antigravity](/blog/claude-code-vs-antigravity/).

## 2. Munder Difflin: if one agent at a time is the bottleneck

[Munder Difflin](https://harnessmd.com/download) is ours, for several agents on research, writing, ops and code side by side. Engines such as Claude Code, Codex and Gemini CLI do the work, so Gemini CLI can stay as one engine. Slack and webhooks bring jobs in; MCP servers, skills and plugins add tools. A Cloud Office and a mobile app are coming soon. Today, agents run while your computer runs. See [how to install and use Munder Difflin](/blog/how-to-install-and-use-munder-difflin/).

## 3. Claude Code: if you want Anthropic's models

Our view: Claude Code is the swap if model quality matters more to you than open source. Its [overview](https://code.claude.com/docs/en/overview), read 4 Nov 2026, says it is "Available in your terminal, IDE, desktop app, and browser".

[Anthropic's pricing page](https://claude.com/pricing), read 4 Nov 2026, leaves Claude Code out of Free and includes it in Pro at $17 a month billed annually or $20 monthly, with Max at $100 and Ultra at $200. Our [Gemini CLI vs Claude Code](/blog/gemini-cli-vs-claude-code/) page goes feature by feature.

## 4. Codex CLI: if you already pay for ChatGPT

Codex CLI is "a coding agent from OpenAI that runs locally on your computer", per its [README](https://github.com/openai/codex), Apache 2.0, with rust-v0.166.0 out on 29 Oct 2026. On [OpenAI's pricing page](https://developers.openai.com/codex/pricing), read 4 Nov 2026, Plus at $20 a month is the first plan with "Codex on the web, in the CLI, in the IDE extension, and on iOS", using GPT-6.1 Sol and GPT-6 Luna. Pro starts at $100 a month as of 4 Nov 2026, and an API key bills at API pricing. See [Codex vs Gemini CLI](/blog/codex-vs-gemini-cli/).

## 5. OpenCode: if you want any provider

We think OpenCode suits you if you liked choosing your own key. It is MIT licensed and shipped [v2.2.5](https://github.com/anomalyco/opencode/releases) on 30 Oct 2026. Its [providers page](https://opencode.ai/docs/providers/), read 4 Nov 2026, claims "75+ LLM providers" plus local models, Google Vertex AI among them. The [v2.2.3 notes](https://github.com/anomalyco/opencode/releases/tag/v2.2.3) add a Claude Agent provider "to use your Claude Code login and models", in OpenCode's words.

## 6. Qwen Code: if you liked Gemini CLI itself

We think Qwen Code is the most familiar swap: its [README](https://github.com/QwenLM/qwen-code) says it "was originally based on Google Gemini CLI v0.8.2" before it "stopped syncing with upstream". It is Apache 2.0 and shipped v0.26.7 on 4 Nov 2026. It "Supports OpenAI, Anthropic, Gemini, and Qwen APIs", plus local models through Ollama or vLLM.

If you came for a free tier, keep walking. The [auth docs](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/auth/), read 4 Nov 2026, say "The Qwen OAuth free tier was discontinued on 2026-04-15", so you bring an API key or an Alibaba Cloud Coding Plan.

## When should you stay on Gemini CLI?

Stay if your company already pays for Gemini Code Assist Standard or Enterprise. Google's announcement tells those customers "your access remains unchanged" and promises "access to the latest Gemini models and other updates." Scripts built on `gemini -p --output-format json` are another reason not to rush.
