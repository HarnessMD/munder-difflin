## What is OpenHands?

OpenHands is a platform for coding agents, and its main repo ships Agent Canvas, a control center that runs them. The [README](https://github.com/OpenHands/OpenHands), read 19 Nov 2026, calls Agent Canvas "The self-hosted developer control center for coding agents and automations" and says: "Run OpenHands, Claude Code, Codex, Gemini, Pi, OpenCode, or any ACP-compatible agent across local, remote, and cloud backends." The code is MIT licensed, and the repo had 93,785 stars on 19 Nov 2026.

It "runs locally on your machine by default". Agents can also run "in Docker containers, on VMs, or within your company infrastructure", or on OpenHands Cloud, which the [Cloud docs](https://docs.openhands.dev/openhands/usage/cloud/openhands-cloud) call "the hosted cloud version of OpenHands". The README says a cloud server "allows your agents to continue running even when your laptop is shut".

## What changed in OpenHands v1.42.0?

Version 1.42.0, dated 18 Nov 2026, brings small changes. The [release notes](https://github.com/OpenHands/OpenHands/releases/tag/v1.42.0) add a cloud feature to "pick the exact connected git provider for repositories" and a fix to "restore native webhook source validation" for automations. It follows [v1.41.0](https://github.com/OpenHands/OpenHands/releases/tag/v1.41.0) of 16 Nov 2026, which added a way to "group the dashboard list by tag". The macOS note says "The app isn't signed with an Apple Developer ID yet".

## How much does OpenHands cost?

Self hosting is free. On 19 Nov 2026 the [pricing page](https://www.openhands.dev/pricing) listed Open Source as "Free", with "Bring your own LLM key". On 19 Nov 2026 Teams cost $500 a month, "10 users included (+$50/mo per seat)", with SSO and a 30 day trial. Enterprise is "Custom pricing". The page caps Teams at 5,000 sessions a month. It printed no separate price for OpenHands Cloud.

## Why look for an OpenHands alternative?

Our view: look if you want one agent rather than a control center, or a lighter install. The README's no sandbox option "runs the agent-server directly on the machine you're installing on", with "full access to your filesystem". The safer routes need Docker. If none of that applies, read this as tools like OpenHands to compare before you pick.

## 1. OpenCode: the closest match to OpenHands

We think OpenCode is the nearest fit. Its [README](https://github.com/anomalyco/opencode), read 19 Nov 2026, calls it "The open source AI coding agent." It runs in a terminal or a desktop app in beta. It is MIT licensed with 227,854 stars on 19 Nov 2026, and the [npm registry](https://registry.npmjs.org/@opencode/cli) lists `@opencode/cli` 2.3.2, published 18 Nov 2026. Agent Canvas can run it too, so OpenHands is happy to drive its closest rival. We think it suits developers who want one agent in the terminal, not a control center. More in [OpenCode alternatives](/blog/opencode-alternatives/).

## 2. Munder Difflin: a team of agents for wider work

Munder Difflin gives you a team of agents, not one agent or one control center for code. Its [README](https://github.com/HarnessMD/munder-difflin), read 19 Nov 2026, says it "Wraps Claude Code, Antigravity (Gemini), OpenAI Codex, xAI Grok, Kimi Code, Gemini CLI, Qwen, OpenCode, Crush, pi.dev, GitHub Copilot CLI, and Cursor, with bring-your-own keys and local LLMs." So OpenCode or Claude Code can be one member of a team that also does research, writing and ops. Its agents can use MCP servers, skills and plugins, and pick up work from Slack or webhooks. The Cloud Office runs your agents in the cloud, always on, so work goes on with your computer off. We think it suits people who want agents for code and the work around it. Setup: [how to install and use Munder Difflin](/blog/how-to-install-and-use-munder-difflin/).

## 3. goose: one open source agent for code and more

goose is one general purpose agent with a desktop app, a CLI and an API. Its [README](https://github.com/aaif-goose/goose), read 19 Nov 2026, says "goose is a general-purpose AI agent that runs on your machine". It works with "15+ providers" and connects to "70+ extensions" over the Model Context Protocol. It is Apache 2.0. [v1.60.1](https://github.com/aaif-goose/goose/releases/tag/v1.60.1) came out on 18 Nov 2026. We think it suits people who want one agent for code and other tasks.

## 4. Cline: a coding agent in your editor

Cline puts an open source coding agent in your editor. Its [README](https://github.com/cline/cline), read 19 Nov 2026, calls it "The open source coding agent in your IDE, terminal, & desktop" and says "Every file edit and terminal command requires your approval", unless you turn on auto approve. The code is Apache 2.0, but the README also says "Currently we are not open-sourcing JetBrains plugins". [v4.1.26](https://github.com/cline/cline/releases/tag/v4.1.26) came out on 26 Oct 2026. We think it suits people who want the agent inside their editor. See [Cline alternatives](/blog/cline-alternatives/).

## 5. Claude Code: Anthropic's own agent

Claude Code is Anthropic's own coding agent. Its [README](https://github.com/anthropics/claude-code), read 19 Nov 2026, calls it "an agentic coding tool that lives in your terminal". The [setup docs](https://code.claude.com/docs/en/setup) say "Claude Code requires a Pro, Max, Ultra, Team, Enterprise, or Console account." Its [licence file](https://github.com/anthropics/claude-code/blob/main/LICENSE.md) says "All rights reserved", so it is not open source. [v2.1.328](https://github.com/anthropics/claude-code/releases/tag/v2.1.328) came out on 19 Nov 2026. We think it suits people who already use Claude.

## How to choose

Pick by what you want to run. Our view:

- An open source agent you run yourself, in a terminal or a desktop app: OpenCode.
- A team of agents for code, research, writing and ops, on your computer or in the Cloud Office: Munder Difflin.
- One general purpose agent with a desktop app, a CLI and an API: goose.
- Your editor, VS Code or JetBrains, with approval on each step: Cline.
- Anthropic's own agent, with a Claude account: Claude Code.
- A self hosted control center that runs several agents and automations: stay on OpenHands.
