Our view: OpenCode is the best Aider alternative, because it is an MIT licensed agent that runs in your terminal and works with many model providers. People look elsewhere because Aider's repo shows no commits since 22 May 2026 and no PyPI release since 12 Feb 2026, checked 20 Nov 2026.

We make [Munder Difflin](https://harnessmd.com/download), which is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. More in our [best AI coding agents](/blog/best-ai-coding-agents/) hub and the pinned [Herdr alternatives](/blog/herdr-alternatives/) guide.

## What is Aider?

Aider is an open source pair programmer that runs in your terminal and commits its changes to git. Its [site](https://aider.chat/), read 20 Nov 2026, says "Aider lets you pair program with LLMs to start a new project or build on your existing codebase." It "can connect to almost any LLM, including local models", and "Aider automatically commits changes with sensible commit messages." The [repo](https://github.com/Aider-AI/aider) is Apache 2.0 licensed and had 50,189 stars on 20 Nov 2026.

## Is Aider still maintained?

The repo is not archived, but GitHub's API on 20 Nov 2026 put the last commit on main at 22 May 2026, with none since. The newest entry on the [releases page](https://github.com/Aider-AI/aider/releases) is v0.86.0, from 9 Aug 2025, and [PyPI](https://pypi.org/project/aider-chat/) lists 0.86.2, uploaded 12 Feb 2026. The README and the site give no status note.

## What are the best Aider alternatives?

Six tools, as of 20 Nov 2026, picked for what Aider users like: a terminal, git and a choice of models. All but Claude Code are open source.

## 1. OpenCode: the closest match to Aider

OpenCode's [README](https://github.com/anomalyco/opencode), read 20 Nov 2026, calls it "The open source AI coding agent." The [docs](https://opencode.ai/docs/) say "It’s available as a terminal-based interface, desktop app, or web app" and "OpenCode has built-in support for many LLM providers." It is MIT licensed with 228,072 stars on 20 Nov 2026, and [v2.3.2](https://github.com/anomalyco/opencode/releases/tag/v2.3.2) came out on 18 Nov 2026. We think it suits Aider users who want one open source agent with a wide choice of models.

## 2. Munder Difflin: a team of agents on the engines you pick

Munder Difflin runs a team of agents, and each can run its own engine, such as Claude Code, Codex or Gemini CLI. Its [README](https://github.com/HarnessMD/munder-difflin), read 20 Nov 2026, says "Each agent runs the real CLI you already use, signed in with your own plan" and "Each agent picks its own, so one office can mix them." You hand them "research, writing, analysis, planning, support, operations, and code too." Agents can use MCP servers, skills and plugins, and take work from Slack or webhooks. The Cloud Office runs your agents in the cloud, always on, so work goes on with your computer off. We think it suits Aider users who want several agents on code and the work around it. Setup: [how to install and use Munder Difflin](/blog/how-to-install-and-use-munder-difflin/).

## 3. Qwen Code: any provider or local model

Qwen Code lets you switch models while you work. Its [README](https://github.com/QwenLM/qwen-code), read 20 Nov 2026, calls it "The open-source AI coding agent for your terminal, editor, desktop, browser, and chat." It "Supports OpenAI, Anthropic, Gemini, and Qwen APIs. Any third-party provider or local model (Ollama / vLLM). Switch at runtime." Its `/auth` command takes a Qwen subscription or an API key. It is Apache 2.0 with 30,792 stars on 20 Nov 2026, and [v0.28.0](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.0) came out on 17 Nov 2026. We think it comes closest to Aider's promise of almost any model, local ones included.

For a model to run locally, [Inkling 2 Mini](/blog/inkling-2-mini/) is a new open weights model that Thinking Machines says runs on a laptop, checked 21 Nov 2026.

## 4. goose: one agent for code and more

goose is one agent with a desktop app and a CLI. Its [README](https://github.com/aaif-goose/goose), read 20 Nov 2026, says "goose is a general-purpose agent for coding, research, writing, automation, and data analysis." You can "Load local models directly inside goose, without a separate model server, or connect to over 85 providers". It is Apache 2.0 with 56,796 stars on 20 Nov 2026, and [v1.60.1](https://github.com/aaif-goose/goose/releases/tag/v1.60.1) came out on 18 Nov 2026. We think it suits people who want one agent for more than code; see [goose alternatives](/blog/goose-alternatives/).

## 5. Codex CLI: OpenAI's open source agent

Codex CLI is OpenAI's agent, and it is Apache 2.0 licensed. Its [README](https://github.com/openai/codex), read 20 Nov 2026, says "Codex CLI is a coding agent from OpenAI that runs locally on your computer." You sign in with ChatGPT "to use Codex as part of your Plus, Pro, Business, Edu, or Enterprise plan", or use an API key, which "requires additional setup". It had 135,906 stars on 20 Nov 2026, and [0.171.0](https://github.com/openai/codex/releases/tag/rust-v0.171.0) came out on 20 Nov 2026. We think it suits people who already pay for ChatGPT.

## 6. Claude Code: closed source, from Anthropic

Claude Code is Anthropic's agent, and it is not open source. Its [README](https://github.com/anthropics/claude-code), read 20 Nov 2026, calls it "an agentic coding tool that lives in your terminal" that helps with "handling git workflows". Its [licence file](https://github.com/anthropics/claude-code/blob/main/LICENSE.md) says "All rights reserved", and the [setup docs](https://code.claude.com/docs/en/setup) say "Claude Code requires a Pro, Max, Ultra, Team, Enterprise, or Console account." It had 156,350 stars on 20 Nov 2026, and [v2.1.329](https://github.com/anthropics/claude-code/releases/tag/v2.1.329) came out on 19 Nov 2026. We think it suits Aider users who already pay for Claude; see [Aider vs Claude Code](/blog/aider-vs-claude-code/).

## How to choose

Pick by what you liked about Aider. Our view:

- Many providers, open source, in the terminal: OpenCode.
- A team of agents for code, research and writing, on your computer or in the Cloud Office: Munder Difflin.
- Local models, with a switch at runtime: Qwen Code.
- One agent for code and other work, with a desktop app: goose.
- Your ChatGPT plan: Codex CLI.
- Your Claude plan, if closed source is fine: Claude Code.
- Aider as it is, with no commits since 22 May 2026: stay on Aider.
