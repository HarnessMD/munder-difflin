Our view: Orca is the closest Emdash alternative today, and Emdash itself is still a sound pick. On 5 Nov 2026 Emdash renamed its desktop app Emdash Classic and moved new development to Emdash 2.0, a team cloud product in early access. Checked 6 Nov 2026.

[Munder Difflin](https://harnessmd.com/download) is free and open source: a desktop app that runs a team of AI agents for all kinds of knowledge work, coding included, on your own computer. More pages like this sit in our [Comparisons hub](/blog/topics/comparisons/).

## What is Emdash?

Emdash is a desktop app for running several coding agents at once, each in its own Git worktree. Its [README](https://github.com/generalaction/emdash), read 6 Nov 2026, says: "Each task runs in its own Git worktree, so you can explore multiple fixes or features at once, review the diffs, and merge what works."

It runs on macOS, Windows and Linux, and on remote machines over SSH. The [providers page](https://emdash.com/docs/providers) says "Emdash supports 35 coding agent CLIs." Issues can come in from Linear, GitHub, Jira and more. The licence is Apache 2.0, and the [latest release](https://github.com/generalaction/emdash/releases/latest), v1.2.11, shipped on 6 Nov 2026.

## Why look for an Emdash alternative now?

Because new features are going somewhere else. Emdash's post [What's next for Emdash](https://emdash.com/blog/whats-next-for-emdash), dated 5 Nov 2026, says: "We're building Emdash 2.0: coding agents for your whole team." It adds: "The current desktop app is now called Emdash Classic. It stays open source and keeps getting fixes."

The [Classic page](https://emdash.com/classic), read 6 Nov 2026, says new development "has moved to Emdash 2.0" and advises: "If you can, start with 2.0." The [home page](https://emdash.com) describes 2.0 as agents "on your own infrastructure or Emdash cloud", behind an early access form. The v1.2.11 notes add "an in-app signup for Emdash 2.0 early access."

Classic still works. If you want a local app that keeps gaining features, or are comparing before you pick, read on.

## 1. Orca: the closest match

We think Orca is the nearest match, with a phone app on top. Its [README](https://github.com/stablyai/orca), read 6 Nov 2026, says: "Run Claude Code, Codex, and any other coding agent in parallel, each in its own worktree." It also says "Your agents keep running when your laptop sleeps" if you give a worktree "its own cloud VM". The [Orca site](https://www.onorca.dev) answers "Is it free?" with "Free and open source." See [Orca vs Munder Difflin](/blog/orca-vs-munder-difflin/).

## 2. Munder Difflin: a team for more than code

[Munder Difflin](https://harnessmd.com/download) is ours. It runs engines such as Claude Code, Codex and Gemini CLI, takes work from Slack and webhooks, and adds tools through MCP servers, skills and plugins. Agents run while your computer runs. Its [README](https://github.com/HarnessMD/munder-difflin), read 6 Nov 2026, lists "Per-agent git worktrees. Optional isolation so parallel agents never collide on branches." A Cloud Office and a mobile app are coming soon. Start with [how to install and use Munder Difflin](/blog/how-to-install-and-use-munder-difflin/).

## 3. Orchestrator.inc: if you want pull requests carried to merge

Orchestrator.inc puts one main agent in charge of the workers. Its [README](https://github.com/OrchestratorInc/agent-orchestrator), read 6 Nov 2026, says the main agent "plans the work, starts a worker for each piece in its own worktree", and that "Failed checks, review comments, and merge conflicts go back to the worker that owns the branch". Its [pricing page](https://orchestrator.inc/pricing/), read 6 Nov 2026, lists Free at $0 for local use, with Starter at $20 and Pro at $40 a month for cloud agents. See [Orchestrator.inc vs Munder Difflin](/blog/orchestrator-inc-vs-munder-difflin/).

## 4. T3 Code: if you steer from a phone

T3 Code is a front end for the agents already on your machine. Its [README](https://github.com/pingdotgg/t3code), read 6 Nov 2026, calls it an "agent harness control surface" with a mobile app, a web app and a desktop app. The [T3 Code site](https://t3.codes) says it is "free, open source and fast". The README is honest: "We are very very early in this project. Expect bugs."

## 5. Worktrunk: if you only want the worktrees

Worktrunk skips the app entirely. Its [README](https://github.com/max-sixty/worktrunk), read 6 Nov 2026, calls it "a CLI for git worktree management, designed for running AI agents in parallel". The command `wt switch -c -x claude feat` makes a worktree and starts Claude Code inside it. We cover the trade offs in [Worktrunk alternatives](/blog/worktrunk-alternatives/).

## 6. Claude Code --worktree: if you add nothing

You may not need a new tool at all. Anthropic's [worktrees docs](https://code.claude.com/docs/en/worktrees.md), read 6 Nov 2026, say: "Pass `--worktree` or `-w` with a name to create an isolated worktree and start Claude in it." To get a second session, "Run the command again with a different name in another terminal". No board, no diff screen, just the terminal you already have open.

## What did we leave out?

Two tools that would otherwise fit. [Conductor's announcement](https://www.conductor.build/announcement), read 6 Nov 2026, says it is joining Meta, that from 4 Nov "New users can no longer sign up for Conductor or download the app", and that local Conductor "will start winding down in early 2027". Our [Conductor alternatives](/blog/conductor-alternatives/) page has the full timeline. [Claude Squad](https://github.com/smtg-ai/claude-squad) last released v1.0.20 on 20 Aug 2026, per its GitHub releases, so we kept to tools that shipped more recently.

## Which one should you pick?

Our view: pick Orca for the closest swap with a phone and cloud VMs. Pick Munder Difflin if you want a team of agents on research, writing, ops and code. Pick Orchestrator.inc if pull requests are the whole job, T3 Code if you steer from your phone, and Worktrunk or Claude Code's flag if you only want worktrees. Or stay on Emdash Classic if it works for you, since it still gets fixes.
