Our picks for a Claude Code alternative are Codex CLI if you want the closest swap, OpenCode or Pi if you want open source with any model, and Cursor or Cline if you want the agent inside an editor. Checked 5 Oct 2026.

This list is for people who use Claude Code, or nearly did, and want something else. Our [Comparisons hub](/blog/topics/comparisons/) has the head to head posts, and [best AI coding agents](/blog/best-ai-coding-agents/) ranks the whole field.

## Why look for a Claude Code alternative?

We see four reasons people look elsewhere: price, licence, model choice, or wanting an editor. On 5 Oct 2026, [Anthropic's pricing page](https://claude.com/pricing) put Claude Code in Claude Pro ($20 if billed monthly) and Max (from $100 a month), and not in the Free plan.

The Claude Code repo is public, but its licence file says "All rights reserved", so it is not open source; [is Claude Code open source](/blog/is-claude-code-open-source/) explains why that matters. It is also built around Claude models. If none of that bothers you, stay: it is a good tool.

## Seven alternatives, plus a different kind of tool

**1. Codex CLI.** [Codex CLI](https://github.com/openai/codex) is OpenAI's "coding agent from OpenAI that runs locally on your computer". The code is Apache 2.0. OpenAI's [pricing page](https://learn.chatgpt.com/docs/pricing) lists the CLI from ChatGPT Plus, which was $20 a month on 5 Oct 2026, or you can use an API key. Its help centre says Codex is included in Free and Go too, but those cards on the pricing page list the desktop app only. Best for: the same way of working, on OpenAI models. More in [Codex vs Claude Code](/blog/codex-cli-vs-claude-code/).

**2. Munder Difflin.** [Munder Difflin](https://harnessmd.com/download) is what we make, and it is not a replacement for Claude Code. It is a different kind of tool: a free and open source desktop app that runs a team of coding agents such as Claude Code, Codex and Gemini CLI on your own computer. It fits you if you want to mix or switch agents without choosing one. You still install each CLI and sign in with your own plan or key. Start with [how to install and use Munder Difflin](/blog/how-to-install-and-use-munder-difflin/).

**3. OpenCode.** [OpenCode](https://opencode.ai/) is an MIT licensed agent for your terminal, IDE or desktop. Its site says "free models included or connect any model from any provider", with 75+ providers and local models. OpenCode Go was $10 a month on 5 Oct 2026. Best for: model freedom. See [what is OpenCode](/blog/what-is-opencode/).

**4. Cursor.** [Cursor](https://cursor.com/pricing) is a proprietary editor with an agent built in, plus a CLI. Hobby is free with limited Agent requests, and Individual was $20 a month on 5 Oct 2026. Its docs list models from OpenAI, Anthropic, Google and SpaceXAI. Best for: people who think in an editor. See [Claude Code vs Cursor](/blog/claude-code-vs-cursor/).

**5. Gemini CLI.** [Gemini CLI](https://github.com/google-gemini/gemini-cli) is Google's Apache 2.0 terminal agent for Gemini models. Read the fine print: Google's [transition notice](https://github.com/google-gemini/gemini-cli/discussions/27274) set 18 Jun 2026 as the day it stops serving free, Google AI Pro and Ultra users, while paid Gemini API keys keep working. Those tiers are now supported through Antigravity CLI. The repo README still advertises a free tier, which the notice overrides. Best for: teams already paying Google.

**6. Cline.** [Cline](https://cline.bot/pricing) is an Apache 2.0 agent that ships as a VS Code extension and a CLI. Its pricing page says it "is free for individual developers" and you pay only for inference, with your own keys or through Cline. Best for: an open agent inside stock VS Code.

**7. Pi.** [Pi](https://pi.dev/) is an MIT licensed "minimal agent harness". It supports 15+ providers and skips sub-agents and plan mode on purpose: you add them as extensions. Version 1.0.3 came out on 5 Oct 2026. Best for: people who want to build their own setup. See [what is Pi agent](/blog/what-is-pi-agent/).

**8. Aider.** [Aider](https://aider.chat/) is Apache 2.0 "AI pair programming in your terminal", and it commits every edit to git. It is free with your own API keys. One flag: PyPI's newest version on 5 Oct 2026 was 0.86.2, uploaded 12 Feb 2026. Best for: git first work, if the slow release pace is fine with you.

## What is the closest alternative to Claude Code?

Codex CLI is the closest, in our view. Both are terminal agents made by a model lab, and the first plan that lists each CLI costs $20 a month (5 Oct 2026). The licence is the real difference.

## Is there a free Claude Code alternative?

Yes: OpenCode includes free models, and Cline, Pi and Aider are free software that bill you only through your model provider. Cursor's Hobby plan is free too, with limited Agent requests. ChatGPT Free includes limited Codex access, though the Codex pricing page lists only the desktop app on that plan.

## Who should pick what?

Pick by the reason you are leaving. The coin stacks above are level for a reason: three of them cost exactly $20, Claude Pro included (5 Oct 2026), so price alone rarely settles it.

<figure class="mg" data-scene="pegs"><img src="/blog/assets/media/claude-code-alternatives/pegs.png" width="1600" height="1200" loading="lazy" decoding="async" alt="Animation. Seven pegs pop up in turn, each standing for a reason to leave, and each one drops into the only tile it fits."><figcaption>Seven reasons, seven tools: each peg fits one hole.</figcaption></figure>

- **You want the same workflow, different lab:** Codex CLI.
- **You want to keep Claude Code and add others:** Munder Difflin.
- **You want any model, local ones included:** OpenCode.
- **You want an editor:** Cursor, or Cline if you are staying in VS Code.
- **You already pay for Gemini API access:** Gemini CLI.
- **You want to build your own harness:** Pi.
- **You want every change in git:** Aider.
