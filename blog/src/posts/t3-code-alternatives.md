## What is T3 Code?

T3 Code is a free, MIT licensed app that controls the coding agents already set up on your computer. Its [README](https://github.com/pingdotgg/t3code), read 3 Nov 2026, calls it an "agent harness control surface", with a mobile app, a web app and an Electron desktop app. It "Works with your subscriptions on Claude Code, Codex, Cursor, Grok Build, OpenCode, Google Antigravity, and fx."

On cost, its [FAQ](https://github.com/pingdotgg/t3code/blob/main/docs/user/faq.md) says: "Nothing. There's no way to pay us to use T3 Code." You still pay each agent's plan. T3 Connect, its remote link, is "free too, for now" for up to 3 machines per account.

## Why would you leave T3 Code?

Five reasons, from T3 Code's own docs, read 3 Nov 2026:

* The README says: "We are very very early in this project. Expect bugs."
* It is "(mostly) not accepting contributions yet."
* The FAQ says T3 Code drives Claude through Anthropic's Agent SDK and "all Agent SDK usage will drain your 5h limits faster than using Claude Code directly". Weekly limits are not affected, it adds.
* Asked "Does T3 Code support local models?", the FAQ answers "No."
* "The phone is a remote. Your computer does the work and needs to stay on."

## 1. Claude Code desktop: if Claude is your main agent

Our view: go to the source if most of your threads run Claude. In the Claude Desktop app, Claude Code is "the **Code** tab", per Anthropic's [desktop docs](https://code.claude.com/docs/en/desktop), read 3 Nov 2026. It runs parallel sessions on your machine, over SSH or in the cloud, and cloud sessions "continue even if you close the app or shut down your computer". Dispatch sends it tasks from your phone on Pro, Max or Ultra.

The same docs ask for "an active paid subscription: Pro, Max, Ultra, Team, or Enterprise". [Anthropic's pricing page](https://claude.com/pricing), read 3 Nov 2026, puts Pro at $17 a month billed annually or $20 monthly. More in [what Claude Code costs](/blog/how-much-does-claude-code-cost/).

## 2. Munder Difflin: if you want a team for more than code

[Munder Difflin](https://harnessmd.com/download) is what we make, and it fits if you want several agents on research, writing, ops and coding, not only threads in one repo. It runs on engines such as Claude Code, Codex and Gemini CLI. Work comes in from Slack and webhooks, and tools connect through MCP servers, skills and plugins. As with T3 Code, agents run while your computer runs. A Cloud Office and a mobile app are coming soon. Setup is in [how to install and use Munder Difflin](/blog/how-to-install-and-use-munder-difflin/).

## 3. Codex in the ChatGPT app: if Codex is your main agent

OpenAI's own app is the swap if your threads are mostly Codex. Its [desktop app guide](https://learn.chatgpt.com/docs/app), read 3 Nov 2026, says you "Choose ChatGPT or Codex", run projects in parallel and schedule tasks, on macOS, Windows or Linux. On [OpenAI's pricing page](https://learn.chatgpt.com/docs/pricing), read the same day, Free and Go ($8 a month) list GPT-6 Luna "in the desktop app, subject to rollout", and Plus is $20 a month.

## 4. Orca: if you want many agents, still open source

We think Orca is the closest swap for a T3 Code user who runs many agents. Its [README](https://github.com/stablyai/orca), read 3 Nov 2026, says it "Works with any CLI agent" and runs each one "in its own worktree, tracked in one place". A phone companion lets you "Monitor and steer your agents", it runs on macOS, Windows and Linux, and it "is free and open source under the MIT License". [v1.4.247](https://github.com/stablyai/orca/releases/tag/v1.4.247) shipped on 3 Nov 2026.

## 5. Conductor: if work should go on with the app closed

Conductor is the pick if closing the app should not stop the work. Its [home page](https://www.conductor.build), read 3 Nov 2026, says it "runs the first-party Claude Code, Codex, Cursor, and OpenCode agents under the hood". Its [pricing page](https://www.conductor.build/pricing), same day, says a cloud workspace means "even if you close the Conductor app, work continues". Free covers "Local workspaces on your Mac". Pro, at $50 a month on 3 Nov 2026, adds Conductor Cloud, cloud workspace hours and the mobile app.

## 6. OpenCode desktop: if you want local models

OpenCode is the answer if T3 Code's "No" on local models is the deal breaker. Its [providers page](https://opencode.ai/docs/providers/), read 3 Nov 2026, says it supports "75+ LLM providers" and "running local models". The [README](https://github.com/anomalyco/opencode) lists a "Desktop App (BETA)" for macOS, Windows and Linux. It is MIT licensed, and [v2.2.5](https://github.com/anomalyco/opencode/releases/tag/v2.2.5) came out on 30 Oct 2026. It is one agent, not a control surface for several. See [OpenCode alternatives](/blog/opencode-alternatives/).

## When should you stay on T3 Code?

Stay if remote control of several agents from one window is why you came. The FAQ says you can run `npx t3 up` "on any box and drive it from anywhere", and the v0.1.6 notes list "521 changes from 137 contributors". Our view: for an app that calls itself very early, that pace is a reason to keep watching it.
