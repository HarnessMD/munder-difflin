Claude Cowork is Anthropic's agent for office work: you describe an outcome, Claude plans it, runs the steps in the background and hands back finished files. It comes with every paid Claude plan, from $20 a month (checked 3 Oct 2026), and not with the free one. Since 16 Sep 2026 it is being merged into normal Claude chat.

Cowork is built for documents, spreadsheets and research. If your work is a codebase and you want several coding agents at once, that is a different tool: [Munder Difflin](https://harnessmd.com/download), free and open source, is a desktop app that runs a team of coding agents such as Claude Code, Codex and Gemini CLI on your own computer. The [install guide](/blog/how-to-install-and-use-munder-difflin/) covers setup, and the [concepts hub](/blog/topics/concepts/) has more.

## What is Claude Cowork?

Claude Cowork is a mode of Claude that does a multi-step task for you, where chat only answers a message. Anthropic's [help page](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork) says it "uses the same agentic architecture that powers Claude Code, with no terminal required".

The help page and the [product page](https://claude.com/product/cowork) list what it works with:

* **Your files.** On desktop, Claude reads and writes local files with no upload step, but only in folders you have connected.
* **A browser.** Claude can open sites, read pages, click, type and fill forms.
* **Your apps.** Connectors link outside tools. Plugins bundle skills, connectors and sub-agents for a role or team, and one you add also works in chat and Claude Code.
* **Office formats.** Word documents, PDFs, spreadsheets with working formulas, and presentations.
* **Schedules.** Tasks can repeat on a timer.
* **Sub-agents.** Claude breaks large work into smaller tasks that run side by side.

## How much does Claude Cowork cost?

Cowork has no price of its own: it is included in every paid Claude plan. The help page says it is "available to paid Claude plans (Pro, Max, Team, Enterprise) only". Prices below are in US dollars from [claude.com/pricing](https://claude.com/pricing) and Anthropic's [Max plan article](https://support.claude.com/en/articles/11049741-what-is-the-max-plan), checked 3 Oct 2026.

| Plan | Price (checked 3 Oct 2026) | Cowork included? |
| --- | --- | --- |
| Free | $0 | No |
| Pro | $20 a month, or $17 a month billed annually ($200 up front) | Yes |
| Max 5x | $100 a month, monthly only | Yes |
| Max 20x | $200 a month, monthly only | Yes |
| Team Standard seat | $25 a seat monthly, or $20 billed annually | Yes |
| Team Premium seat | $125 a seat monthly, or $100 billed annually | Yes |
| Enterprise | $20 a seat a month billed annually, plus usage at API rates | Yes, where an admin allows it |

There is no separate Cowork allowance in that table, because tasks draw on your plan's usage. The help page warns that multi-step tasks which run code, create files or use your connected apps and browser "use more of your usage than a quick question". ## Which platforms does Claude Cowork run on?

Five surfaces, by the help page's availability list on 3 Oct 2026:

* **Claude Desktop for macOS and for Windows:** all paid plans.
* **Web, at claude.ai:** Pro, Max and Team. Enterprise where an admin enables it.
* **Claude mobile apps:** Pro, Max and Team. Enterprise where an admin enables it.
* **Chrome side panel:** Max and Team, with Pro still rolling out. Enterprise where an admin enables it.

Where the work runs is changing. The help page says "Claude's work runs on Anthropic's servers, in an isolated environment", and labels the cloud sessions as beta. It also carries a dated notice for Pro and Max plans: "On October 6, 2026, new Cowork tasks run in the cloud and the Only on your computer option in Settings > General will be removed." Tasks you already started on your computer stay there. The notice does not cover Team or Enterprise.

## How do you use Claude Cowork?

Pick Cowork in the message box and describe the result you want. The steps, following the help page:

1. Get a paid plan. Pro is enough.
2. Open Claude at claude.ai, in the Claude Desktop app, or in the mobile app.
3. In the message box, select Cowork. If your account already has the merged app, skip this and just ask.
4. Describe the task as an outcome: what you want back, in which format, from which files.
5. Review Claude's approach, then let it run.
6. For local files, browser use or computer use, keep the Desktop app open and connected, and connect only the folders the task needs.
7. To repeat a task, type `/schedule` inside it.

You also choose how often Claude stops to ask. It can pause for approval on each action (Manual, the default), keep going in auto mode, where it reviews each action for safety and blocks what it judges unsafe, or skip approvals entirely, which Anthropic says to use only when you completely trust everything involved. In the merged app the message box offers only Auto and Manual. Anthropic notes that auto mode "consumes more of your usage limit than the other modes".

## What can Claude Cowork not do?

It cannot run on the free plan, work offline, or reach files you have not shared. The limits Anthropic states:

* **Internet required.** An active connection is needed throughout the session.
* **Folder fence.** Claude can only read and write in folders you have connected, and it needs your explicit permission before permanently deleting any file.
* **Desktop for local work.** Web and mobile sessions run in the cloud. Local files, browser use and computer use need the Desktop app.
* **Agent risk.** The help page says Cowork "has unique risks due to its agentic nature and internet access". Treat a web page it reads as untrusted input.
* **Deletion lag.** A deleted task leaves your history at once and leaves Anthropic's backend storage within 30 days.

## Claude Cowork vs Claude Code: which one do you need?

Cowork for documents, Claude Code for software. Anthropic's product page describes Claude Code as built for software engineering (writing, debugging and shipping code) and Cowork as built for non-coding knowledge work.

Pick Claude Code when the output is a commit. If you want always on agents from another vendor, our [ChatGPT dots explainer](/blog/what-is-chatgpt-dots/) covers OpenAI's version.
